> 生成时间：2026-08-19 ｜ 配套：《Agent知识库建设方案.md》第二章
> 前置：20 份源文件已全部解析为纯文本（`源文件解析文本/`，可检索）
> 策略：**先概念层（本体+概念字典）→ 后实例层（实体三元组）**，实例层需医学审核。

---

## 一、图谱分层策略

| 层 | 内容 | 依赖 | 状态 |
|---|---|---|---|
| **概念层**（本设计） | 实体类型、关系类型、概念字典、三元组模板 | 无（基于领域知识+知识清单） | 本文件产出 |
| **实例层** | 从已解析文本中抽取的具体实体与关系（如 CMPA 具体症状、eHF/AAF 具体适用） | 结构化条目 + 医学审核 | 待启动 |

> 为什么不一步建"大而全"图谱：医疗关系错误代价高；实例抽取必须人工审核，一步到位不现实。

## 二、实体类型（Entity Types）

```
[过敏原]    牛奶蛋白·鸡蛋·花生·坚果·小麦·大豆·海鲜·芝麻
[疾病]      食物过敏·CMPA·特应性皮炎·过敏性鼻炎·哮喘·严重过敏反应·嗜酸性食管炎·FPIES
[症状]      皮疹·荨麻疹·血管性水肿·腹泻·便血·呕吐·拒食·喘息·喉头水肿·哭闹
[检查]      sIgE·SPT·CRD·OFC·斑贴试验·总IgE
[干预]      母乳喂养·特殊配方(eHF/AAF)·辅食引入·饮食回避·免疫治疗·肾上腺素·保湿护理
[风险因素]  家族史·湿疹·剖宫产·早期奶粉暴露·年龄
[人群]      婴幼儿(0-3岁)·孕产妇·哺乳母亲·过敏高风险儿
[机构]      儿科·儿保科·变态反应科·皮肤科
```

## 三、关系类型（Relation Types）

| 关系 | 方向 | 示例三元组 |
|---|---|---|
| `由…导致` | 过敏原 → 疾病 | （牛奶蛋白, 由...导致, CMPA） |
| `表现为` | 疾病 → 症状 | （CMPA, 表现为, 便血）（CMPA, 表现为, 湿疹） |
| `诊断` | 检查 → 疾病 | （OFC, 诊断, CMPA）（sIgE, 诊断, IgE-CMPA） |
| `治疗` | 干预 → 疾病 | （eHF, 治疗, CMPA）（肾上腺素, 治疗, 严重过敏反应） |
| `预防` | 干预 → 疾病 | （早期引入, 预防, 食物过敏）（母乳喂养, 预防, CMPA） |
| `风险因素` | 风险因素 → 疾病 | （重度湿疹, 风险因素, 花生过敏）（剖宫产, 风险因素, 过敏） |

## 五、图谱增强检索示例（预期效果）

**查询**："宝宝喝了奶粉就拉血便，是牛奶蛋白过敏吗？"

```
概念字典：拉血便→便血；奶粉→牛奶蛋白；牛奶蛋白过敏→CMPA
实体链接：
  便血 —(属于)→ CMPA 症状
  CMPA —(鉴别)→ 感染性肠炎 / NEC
检索增强：
  ① 命中 KB-D1（CMPA 症状谱：便血）
  ② 图谱一跳扩展 → KB-C4（回避-激发）→ KB-D2（配方）
  ③ 消歧：区别于"乳糖不耐受"（无血便）
  ④ 风险提示：便血也需鉴别急症 → 引导就医（F6）
```

## 六、实例层构建方法（下一步）

| 步骤 | 做法 | 产出 |
|---|---|---|
| 1. 实体抽取 | 基于已解析文本 + 知识清单条目，半自动抽取实体（LLM 辅助 + 人工校对） | 实体清单（含同义词、来源） |
| 2. 关系实例化 | 按概念层模板填充具体三元组，**每条标注来源文档+页码** | 三元组集（RDF/JSON-LD） |
| 3. 审核 | 医学审核员校验高危关系（治疗/禁忌/诊断类） | 审核记录 |
| 4. 入库 | 存入图数据库（Neo4j）或向量库+关系表 | 可查询图谱 |

> 规模预估：实体 100-150 个、关系三元组 400-600 条（基于 8 模块 40 条目），人工审核可行。
