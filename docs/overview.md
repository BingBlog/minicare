# 敏宝日记 · 产品概述

> 来源：MVP-PRD.md §1-2  
> 最后同步：2026-03-29

## 1.1 产品定位与目标

**敏宝日记**是一款专为 0-1 岁牛奶蛋白过敏（CMPA）宝宝家庭打造的饮食生活记录和健康管理 APP。产品定位为「**敏宝家庭的结构化健康记录工具**」，核心目标是帮助照护者把饮食、表现、生长发育等信息**系统化记录并导出**，方便就医时携带与沟通。

**本版 MVP 约束**：采用原生开发支持 iOS 和 Android 双平台，目标在 **1.5 个自然月内**完成可内测的 MVP。核心特性包括：**家庭多成员共享**（支持多人同步记录和查看同一宝宝数据）、云端数据同步、本地优先离线可用。

**技术架构策略**：MVP 阶段采用「本地优先 + 云端同步」架构，确保用户在离线状态下也能正常记录，网络恢复后自动同步。

## 1.2 目标用户群体

**核心用户（父母）**：25-35 岁，本科及以上学历，一线城市敏宝父母；需要多成员协作记录。

**协作用户（祖辈/保姆）**：50-65 岁；需要简单易用的记录工具；大字体、少输入、语音方式降低门槛。

## 1.3 核心价值主张

- **全场景记录**：饮食、睡眠、活动、生长、表现、医疗等敏宝护理全场景
- **结构化管理**：符合医学记录标准，可一键生成 PDF 报告
- **代际友好设计**：极简界面 + 大字体 + 语音输入
- **家庭协作**：多成员实时同步
- **数据安全**：端到端加密存储

## 1.4 产品边界（MVP 范围）

**P0 级（必做）**：宝宝档案管理、家庭共享与多成员协作、日常记录（饮食/睡眠/活动/尿布/健康/表现）、生长记录、医疗记录、统计报告生成与导出/分享

**本版明确不做（后续迭代）**：
- AI 分析、社区、电商、云端备份与同步
- 任何形式的预警推送
- 激励机制与会员体系
- 合规与隐私政策、上架材料

## 2.2 信息架构与导航

**底部 Tab（4 个）**：

| Tab      | 定位               | 主要下级内容                                                         |
| -------- | ------------------ | -------------------------------------------------------------------- |
| **首页** | 今日任务与快捷入口 | 今日时间线摘要、六大快捷记录入口（饮食/睡眠/活动/尿布/健康/表现）       |
| **记录** | 按类型浏览与补录   | 饮食/睡眠/活动/尿布/健康/表现/生长/医疗等分类列表，支持筛选日期与类型 |
| **统计** | 数据分析与报告     | 选择时间范围 → 数据统计展示 → PDF 导出 → 系统分享/保存到文件         |
| **我的** | 档案与设置         | 宝宝档案编辑、家庭成员管理、大字体开关、数据清空、关于                             |

**页面层级**：核心路径不超过 3 级，不超过 3 次点击到达核心功能。

## 2.3 全局状态与关键规则

- **当前宝宝**：本地仅存多宝宝时的「当前选中」状态；新建记录均写入当前宝宝 ID。
- **时间基准**：记录以用户选择的「发生时间」为准；补录时默认当前时间，可改为历史时间。
- **今日定义**：以自然日 0:00–24:00（按系统时区）聚合首页「今日」统计。
- **返回与保存**：表单页左上角返回；未保存离开时弹出确认（MVP 建议保留防误触）。
