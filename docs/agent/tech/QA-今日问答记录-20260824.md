**1. 蛋白质被处理的程度不同（核心区别）**
- **深度水解配方（eHF）**：把牛奶蛋白切得很碎，切成小分子**短肽**为主，但仍残留一小部分肽段。
- **氨基酸配方（AAF）**：干脆不再用蛋白质/肽，直接用**单体氨基酸**来替代，理论上**完全没有致敏原**。

简单记：**深度水解≈切成小块，氨基酸≈彻底拆成积木**。所以氨基酸配方的"低敏程度"更高。

**2. 适用情况不同（由医生判断）**
- **轻中度牛奶蛋白过敏** → 通常首选**深度水解配方（eHF）**。
- **重度过敏、或吃了深度水解仍不耐受/症状不缓解** → 换成**氨基酸配方（AAF）**。
- 另外，纯母乳喂养的宝宝如果因故停母乳，**新近指南更推荐直接用氨基酸配方**替代，以提高耐受比率。

**3. 治疗周期与转奶方向**
- 初始疗程一般**至少6个月**，或到诊断后**9～12月龄**，具体听医生的。
- 恢复期按**"氨基酸→深度水解→适度水解→整蛋白配方"**的顺序逐步过渡转奶，不是直接跳回普通配方。

**4. 两个提醒**
- 这类低敏配方是**用于治疗**的，**不建议健康宝宝用来"预防过敏"**（没有证据支持，也不应出于预防目的使用）。
- 氨基酸配方通常**口味更苦、价格更高**，宝宝接受度可能差一些，要有耐心慢慢适应。

💡 至于您的宝宝具体该选哪一种，需要结合过敏的严重程度、症状和医生评估来定，**不建议自行更换配方**。本回答仅供参考，不能替代专业医疗建议。
