6.2 口径决策（本可以含糊过去，但必须写死）

项 决定 理由
mealRhythm 近 7 天有记录日的平均每天进食次数（奶顿数 + 辅食顿数），不给达标结论 餐次随月龄与个体差异大，行业无共识阈值
