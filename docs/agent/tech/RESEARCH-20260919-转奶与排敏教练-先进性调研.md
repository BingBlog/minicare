## 0. 结论摘要（先看这 7 条）

| # | 结论 | 对本项目的含义 |
|---|---|---|
| 1 | **长期目标是"耐受重建"而不是"记录管理"**：CMPA 的临床终点是宝宝恢复广谱饮食，~55% 在 1 岁内、>75% 在 3 岁内、>90% 在 6 岁内自然耐受牛奶 | agent 的北极星必须从"回答准不准"改为"**阶次推进了多少**" |
| 2 | **转奶有可工程化的标准算法**：中国指南给出的「7 天第一瓶奶转换法 + 200ml 临界点原则」是一段**确定性状态机**，不是模糊经验 | 可以做成"计划引擎 + 逐日任务卡"，而不只是问答 |
| 3 | **排敏范式已从"回避"翻转为"主动建立耐受"**：LEAP 试验花生过敏降 81%，2025 年真实世界数据显示花生过敏 -43%、全部 IgE 食物过敏 -36%，且**已耐受食物必须持续规律摄入**（每周 2-3 次），否则耐受会丢失 | 现有"一次一种、观察 3-7 天"只是上半句，缺**维持期**与**扩展节奏**，这是本次要补的核心能力 |
| 4 | **安全性完全取决于机制分型（IgE / 非 IgE）**：非 IgE 可在家庭按阶梯引入；IgE 介导必须医院监督；重度/血便/体重不增直接起始氨基酸配方 | 现有 `allergy_level` 只有轻/中/重，**没有机制字段** → 必须先补 `allergy_mechanism`，否则做阶梯推荐是危险动作 |
| 5 | **数字健康领域的先进范式是 JITAI（Just-In-Time Adaptive Intervention）**：2025 年 Holly Health × Loughborough 的 RL 版 JITAI 在 180+ 用户 3 个月实测中显著提升参与度与习惯完成率；UNC 的 AdaptRL 用强化学习逐日生成个体化决策规则 | 提醒不该是定时推送，而应由「易感状态 × 可接受状态」触发；但 MVP 先用规则版 JITAI，不引入 RL |
| 6 | **agent 架构的公认瓶颈是记忆，不是模型**：2025 年记忆综述把记忆分为工作/情节/语义/程序四层，并指出"短时记忆门控 + 长时记忆固化"才构成自我演进回路；长程 agent 需要异步监督（COMPASS 的 Meta-Thinker）防策略漂移 | 宝宝的"过敏档案"= 语义记忆、"每次尝试"= 情节记忆、"转奶/排敏 SOP"= 程序记忆；三件必须落库，不能靠 prompt 现推 |
| 7 | **用户提出的"营养更丰富 + 花销显著降低"需要校准表述**：特殊医学配方本身营养完整（GB 25596 / Codex），并非营养不足；真实收益是**乳糖回归（促进钙吸收 + 益生元效应）、蛋白来源自然化、饮食谱扩展、社交心理减负**，以及**40%-60% 的奶粉支出下降**（氨基酸 400-700 元/800g、深度水解 300-500 元、普通配方约 200-300 元） | PRD 中不能写"医学奶粉营养不够"（不准确且会被专业家长质疑），应写"从限制性饮食走向广谱饮食" |

## 2. 临床线 A｜转奶（配方降阶）的先进做法

### 2.1 阶梯与适用对象

```
氨基酸配方 AAF ──▶ 深度水解 eHF ──▶ 适度水解 pHF ──▶ 普通配方 std
（重度/血便/体重不增）   （轻中度 CMPA 首选）  （仅预防，不治疗）   （终点）
                     ▲ 不可越级、不可并级
```

- **eHF 覆盖绝大多数轻中度 CMPA**：约 90% 以上患儿可耐受；若 eHF 治疗 2-4 周症状无好转，再考虑升 AAF。
- **pHF 是预防用配方，不能用于治疗已确诊 CMPA**——这是家长最常踩的坑，也是 agent 必须主动拦截的错误。
- 羊奶不可替代（与牛奶蛋白交叉反应 >90%）；豆奶/燕麦奶/杏仁奶致敏性低但营养不达标，不能作主奶。

### 2.2 启动条件（Gate）——可以完全枚举的清单

指南与实践材料给出的启动前提高度一致，适合做成"逐项勾选 + 未满足即阻断"的体检表：

1. **时间**：严格回避致敏原 ≥6 个月，且通常已达 9-12 月龄；
2. **症状**：相关症状（腹泻/便血/湿疹/呕吐等）完全消失且稳定无反复；
3. **营养**：生长发育正常、营养状况良好；
4. **辅食**：已顺利添加辅食；
5. **状态**：宝宝健康——无发热/感冒/胃肠不适/出牙不适，湿疹不在活动期，近期未接种疫苗、未使用可能影响胃肠的药物（如抗生素）；
6. **环境**：家长当天可全天观察（建议上午或中午开始，避免傍晚）；
7. **决策**：已经过儿科/消化/过敏专科医生评估（尤其有速发反应史者）。
8. **互斥**：转奶期间**不添加新辅食**。

### 2.3 执行算法｜「7 天第一瓶奶转换法 + 200ml 临界点」

这是中国《婴儿轻中度非 IgE 介导的牛奶蛋白过敏诊断和营养干预指南》（2022）给出的可执行方法，**天然适合程序化**：

```
每日只选"第 1 顿奶"作为转换目标，其余顿次维持旧配方
D1 第1顿 = 1 勺新 + 其余旧
D2 第1顿 = 2 勺新 + 其余旧
...
D7 第1顿 = 全部新配方
──────────────────────────────
若第1顿奶量 ≥200ml 且全程无异常
   → 可把全天所有顿次替换为新配方
若第1顿奶量 <200ml
   → 继续把第 2 顿作为下一个转换目标，累计到 ≥200ml 再全天替换
```

- 国际 iMAP 牛奶阶梯是**另一条等价路径**，面向"已回避、开始重新引入含奶食物"的场景，6 阶：①含奶粉的饼干 → ②小松饼/烘焙品 → ③煎饼/长时间烘焙食品 → ④奶酪 → ⑤酸奶 → ⑥鲜奶或配方奶。核心机理是**加热 → 蛋白变性、基质包裹（小麦）→ 致敏性降低、剂量递增**三因素叠加。
- 两套路径的差异在于**操作对象**：中国法转的是"配方奶的勺数配比"，iMAP 转的是"含奶食物的形态"。本项目的数据模型天然贴合前者（`feeding_formula_mix` 已有 `milk_type` + `scoops`），后者可作为"1 岁后 / 已能耐受 eHF"的延伸阶。

### 2.4 观测项与判定阈值

| 维度 | 需盯的信号 |
|---|---|
| 皮肤 | 新发/加重湿疹、红疹、风团、口唇面部水肿 |
| 消化道 | 呕吐、腹泻、**血便/黏液便**、腹胀、便秘、拒奶、异常哭闹 |
| 呼吸道 | 流涕、咳嗽、喘息、呼吸费力 |
| 全身 | 异常烦躁、精神萎靡、嗜睡 |

判定要点（容易被忽略但很关键）：
- **轻微变化不等于失败**：排便习惯小改变、胀气略多属可继续观察范围，不应立刻中止（过度中止会让家长永远迈不出第一步）。
- **可复现才算反应**：怀疑某阶食物致敏时，等待 1-2 天重试同一食物，若同样症状再出现才判定为反应。
- **反应分级处置**：轻度（局部瘙痒/局部荨麻疹/鼻塞打喷嚏）→ 同阶减量；中重度 → 退回上一已耐受阶，**2-3 个月后重试**；出现 IgE 表现（荨麻疹、肿胀、呼吸困难）→ 立即停止并就医。

### 2.5 安全分层（不可逾越的红线）

| 情形 | 允许路径 |
|---|---|
| 非 IgE 介导（迟发，便血/腹泻/湿疹/肠绞痛） | 可在**家庭**按阶梯引入（仍需医护指导） |
| 低危 IgE 介导、家长受训、有应急药物 | 可在家庭进行**烘焙奶制品**引入 |
| 高危 IgE 介导（近期严重过敏/未控哮喘/极低反应阈值/酪蛋白 sIgE 极高） | **必须医院口服激发试验（OFC）**，禁止家庭阶梯 |
| 重度 / 血便 / 体重不增 | 先 AAF 6 个月，再逐级降阶 |
| >3 岁仍未耐受 | 每 6 个月试第 1 阶，不宜更频繁 |

> 换阶节奏参考：非 IgE 型每一步 1-2 周（FPIAP 建议），研究中有把每阶缩短到 3 天、2 周走完全程的报道（FPIES 除外，需更长）；IgE 型每阶 1 周至 1 个月，高危者更长（有 6 个月/阶的方案）。

### 2.6 药物与新疗法的边界（agent 只识别、不建议）

- **omalizumab（奥马珠单抗）**：2024 年 FDA 批准用于 ≥1 岁、1 种及以上 IgE 介导食物过敏，降低急性反应风险；OUtMATCH 3 期数据显示 16-20 周后 67% 可耐受 ≥600mg 花生蛋白、66% 可耐受 1000mg 牛奶蛋白。**但停药后获益消退，需持续给药**。
- **口服免疫治疗（OIT）**：EAACI 2025 指南对持续 IgE 介导牛奶过敏的儿童（一般 >4 岁）可考虑牛奶 OIT 以达脱敏，无获批商品化产品，须专科实施。
- 这两项属于**医生决策域**。agent 的职责边界：识别"这家可能在讨论 OIT/生物制剂"→ 提供知识科普 + 引导至专科，**不得输出剂量、疗程、适应人群判断**。

## 3. 临床线 B｜辅食排敏的循证范式翻转

### 3.1 从"延迟引入"到"早期引入"

| 证据 | 结论 |
|---|---|
| LEAP（2015，NEJM） | 4-11 月龄高危婴儿规律摄入花生制品，5 岁时花生过敏**降低 81%**，效应延续至青春期 |
| NIAID Addendum（2017）+ 多学会共识（2021） | 推荐 4-6 月龄起引入花生、鸡蛋等过敏原，**弱化前置检测分诊** |
| CHOP 真实世界回顾（Pediatrics 2025，12 万+ 儿童） | 花生过敏 **0.79% → 0.45%（-43%）**，全部 IgE 食物过敏 **1.46% → 0.93%（-36%）**；鸡蛋已超过花生成为首位过敏原；估算每 200 名早期引入的婴儿避免约 1 例食物过敏 |

**对 agent 的直接含义**：敏宝的辅食策略不是"能拖就拖"，而是"**尽早、规律、足量地引入并维持**"。
但要注意两条安全约束：① 高致敏食物（花生/坚果）需**适龄形态**（绝不给整粒坚果）；② 重度湿疹或已确诊鸡蛋过敏的高危婴儿，首次引入应在专科指导下进行。

### 3.2 引入节奏：串行 + 观察 + 维持

```
新食物 A：第 1 天少量 → 观察 3-7 天 → 无异常 → 判定"已耐受"
   ↓ 期间不引入任何其他新食物（串行，避免归因混乱）
新食物 B：...
   ↓ 已耐受食物必须持续摄入：每周 2-3 次（防耐受丢失）
```

- 观察窗口：指南口径 3-5 天（国内）到 5-7 天（部分机构）不等，本项目沿用现有产品设计（默认 3 天、可配 3-7 天）并允许"观察期内出现可疑信号则自动延长"。
- **耐受维持是缺失的一环**：文献中有案例显示，长期不规则暴露后已获得的耐受会丢失。现有 minicare 的 `food_observation` 只有四态与 `observation_days`，**没有"维持打卡"概念**。
- **敏宝缺铁风险高**：辅食首选富铁食物（铁强化米粉），大米致敏性相对低。
- 敏宝辅食**开始时间与健康婴儿一致（4-6 月龄）**，不需要额外延迟（除急性期外）。

### 3.3 FPIAP（食物蛋白诱导过敏性直肠结肠炎）的特别处理

这是敏宝家长最焦虑的场景（便血），也是本项目知识库的高频主题：

- 诊断依赖"回避-激发"：回避 2-4 周症状缓解 → 口服激发试验复现 → 确诊。
- 确诊后继续回避**6 个月或至 9-12 月龄**；部分轻症可采取 1 个月"观察等待"策略。
- 母乳喂养者：母亲依次回避牛奶 → 鸡蛋 → 其他；**母亲需同时补充钙剂与维生素 D**（研究显示忌口母亲钙摄入下降、骨密度降低、骨转换率升高）——这是 agent 应该主动提醒、且现有产品完全没有覆盖的点。
- 预后：约 70% 在 1 岁内耐受，第 2 年可达 90%。

### 3.4 与转奶的互斥关系（排程冲突）

排敏与转奶**不能同时进行**：转奶期间不加新辅食、不接种疫苗，否则出现症状时无法归因。
→ 这意味着 agent 需要一个**统一的"档期调度器"**，把转奶阶次、新食物引入、疫苗接种、生病窗口排进同一条时间轴并检测冲突。这是把两个功能点变成"一个教练"的关键。

## 4. 营养与成本｜事实校准与可用素材

### 4.1 营养：不要写"医学奶粉营养不够"

- 特殊医学用途配方受 GB 25596 与 Codex Stan 72 约束，**营养是完整的**（能量 67-70 kcal/100ml、蛋白 1.6-1.9g/100ml、铁 0.5-1.2mg、钙 47-101mg、维 D 0.85-1.7μg 量级）。
- 真正会缺的是**宝宝这一端**：长期限制性饮食 → 铁（FPIAP 约 15% 出现缺铁性贫血）、钙、维 D 摄入风险上升；以及**母亲端**（忌口期钙与维 D）。
- 转奶带来的营养收益应表述为：
  1. **乳糖回归**：早期 eHF 为吸收障碍设计，多为无乳糖/低乳糖 + 高 MCT；含乳糖 eHF 已被证明**提高钙吸收**、具益生元效应（双歧杆菌/乳酸菌↑、拟杆菌/梭菌↓、短链脂肪酸↑）、口感更好、降低拒奶与味觉厌恶风险；
  2. **蛋白来源自然化 + 饮食谱扩展**：耐受后奶酪、酸奶、含奶烘焙品进入食谱，钙与优质蛋白来源显著变宽；
  3. **社交与心理减负**：摆脱"特殊奶粉"标签，外出就餐与家庭喂养压力下降（家长焦虑是被文献明确点名的干预靶点）。

### 4.2 成本：省钱是真的，且可以量化

| 配方档位 | 市场参考价（800g） | 相对普通配方 |
|---|---|---|
| 氨基酸配方 AAF | 400-700 元 | 约 2-3 倍 |
| 深度水解配方 eHF | 300-500 元 | 约 1.5-2.5 倍 |
| 普通配方 | 约 200-300 元 | 基准 |

- 政府采购中标单价可作交叉印证：婴儿氨基酸配方粉 0.98 元/g、乳蛋白深度水解（无乳糖）0.68 元/g、含乳糖 0.74 元/g。
- 极端案例：8 月龄重度湿疹家庭使用 400 元/罐深度水解，3 天喝完一罐，**月均约 7000 元**，且特医奶粉长期未纳入医保。
- → **"每月省下多少钱"是极强的情感与行为激励素材**，且可精确计算（当日配方构成 × 单价 × 日均奶量）。这是现有 agent 完全没做的"意义可视化"。

### 4.3 一次失败尝试的成本（用来解释"为什么必须做计划"）

一次失败的降阶 = 症状复发 + 退回上一阶段 + **2-3 个月冷却期**。按每阶 1-2 个月计，一次误操作可让整个进程延后 3-5 个月，并带来额外的医疗支出与家长信心损耗。
→ 这直接支撑"**先体检、再计划、逐日执行、可回退**"的产品形态，而不是让家长凭感觉试。

## 5. 干预与架构线 C｜先进性对标

### 5.1 JITAI：把"提醒"升级为"在对的时刻给对的干预"

JITAI（Just-In-Time Adaptive Intervention）是行为健康领域的成熟范式，核心是四要素：**易感状态（vulnerable state）、可接受状态（receptive state）、决策规则（decision rules）、适应机制（adaptation）**。

2025 年的落地证据：

| 项目 | 做法 | 结果 |
|---|---|---|
| Holly Health × Loughborough × Modality（Innovate UK，2024-05→2025-10） | 在 App 内嵌 JITAI，用**强化学习**分析用户行为模式，逐日生成个性化教练信息 | 180+ 用户 3 个月：参与度与习惯完成率显著提升；形成"每日反馈环 → 次日计划"的闭环 |
| UNC AdaptRL（NCT05751993，2025 完成） | 用 RL 生成个体化决策规则，决定"该就哪个行为发消息、用哪种行为改变技术"，每日最多 3 次 | 走通"实时数据 → RL → 个体化消息"工程路径 |
| Frontiers in Digital Health 2025 综述 | 用**多臂老虎机 + 因果推断**框架设计自适应干预，并给出个体/群体双层评估方法 | 方法论参考：把"发不发、发什么"当作可评估的策略 |
| arXiv 2025 现实世界研究（70 名学生，2 周） | 用 Thompson Sampling 优化"接受度 × 可行性"组合奖励 | 发现**被动感知数据可预测"用户此刻是否愿意/能否响应"**，呼应 receptive state |

**对本项目的映射（MVP 用规则，不引入 RL）**：

```
易感状态（该干预）          可接受状态（能干预）           行动
──────────────────────────────────────────────────────────
转奶 D1（新配方首次）        当天上午、家长已查看过记录      → 行动卡置顶 + 提醒
观察期第 2-3 天（易漏记）    近 24h 有喂养记录写入            → 询问反应，引导打卡
耐受维持到期（>3 天未吃）    宝宝无在病状态                   → 提醒安排一次维持摄入
排敏任务停滞 > observation_days  有活跃会话                    → 主动提示"要收尾还是暂停"
转奶失败后进入冷却期         冷却期 ≥2 个月且条件满足        → 提示可重试
症状事件出现                 刚发生（高紧迫）                 → 立即介入 + 分级处置
```

> 关键设计约束：**一次对话最多提示 1 条**（沿用 PROFILE 文档既有结论）——8 条 flag 全倒出来会让助手变成报告机。

### 5.2 医疗场景的 agent 落地证据（说明"护栏 + 升级"是标配）

- **Emory Healthcare（AHA 2025 Scientific Sessions）**：AI 语音 agent 覆盖 2000 名高血压老人，10 周内触达 85%，血压控制率从 1 星提升到 4 星，单次读数成本下降 88.7%；**关键设计是异常读数自动升级到护士或助理**。
- **慢性病 AI 自我管理综述（Front Public Health 2025）**：归纳 AI 的四种角色——个体化决策支持、连续监测与风险预测、**对话式依从/行为教练**、连接医患的 mHealth 平台；并点名挑战：隐私、算法偏见、可解释性、**持续参与度**。
- **工程侧共识（2025 行业综述）**：真正算 agent 的系统必须同时具备**规划、记忆、工具**三个子系统；"只接了几个工具的聊天机器人"占企业部署的绝大多数。
  → 本项目的现有实现（4 个工具 + 单轮 prompt）属于后者，这正是要补的部分。

### 5.3 agent 架构：记忆是瓶颈，且已有分层共识

arXiv 2025 记忆综述（*A Survey of Agent Memory in the Second Half*）给出三个切面：**记忆基质**（模型参数内 / 外部检索）、**认知机制**（感官 / 工作 / 情节 / 语义 / 程序）、**记忆主体**（以用户为中心的个性化 / 以 agent 为中心的经验）。核心论点：**没有"记录-固化-复用"回路，每一次交互都不会让 agent 变强，长程任务会退化成一系列孤立的一次性任务。**

工程界的分层实现（四层记忆）：

| 层 | 内容 | 在本项目的落地对象 |
|---|---|---|
| 工作记忆 | 当前会话上下文 | 最近 20 条历史（已有） |
| **情节记忆** | 带时间与上下文的具体事件 | 每一次转奶尝试、每一次新食物引入、每一次症状事件 |
| **语义记忆** | 从情节中提炼的稳定结论 | "已耐受 12 种食材""当前纯 eHF、已停氨基酸 34 天""牛奶过敏、轻度、非 IgE（待确认）" |
| **程序记忆** | 可复用的技能/方案模板 | 转奶 SOP、排敏 SOP、复诊摘要模板 |

配套的先进实践：
- **选择性遗忘**：按"新近度/相关性/频率（RIF）"对低价值记忆剪枝（艾宾浩斯式），降低长期上下文成本；
- **记忆图而非平铺向量**：(A-MEM / Zettelkasten) 每条记忆带描述、关键词、标签与双向链接，在多跳推理上明显优于纯向量召回 —— 对应"食材 ↔ 症状 ↔ 配方"三者需要跨表关联的场景；
- **异步战略监督**：(COMPASS 分层框架) 主 agent 负责战术执行，Meta-Thinker 异步监控，检测到逻辑死循环或策略漂移时强制转向 —— 对应"转奶停滞 18 天 + 期间 2 次皮疹"这类需要跳出单轮视角的矛盾检测；
- **评估必须从静态 QA 走向动态能力**：工具使用、多步决策、长程反馈才是评测对象，而非单轮问答准确率。

## 7. 设计结论｜agent 的能力增补清单

### 7.1 六项新增能力（对应 PRD-006 的用户故事）

1. **敏宝档案与里程碑**（语义记忆基线）：机制分型、阶梯位置、已耐受食材（归一化后）、里程碑进度；
2. **今日行动卡**（规则版 JITAI）：每天最多 1 个主行动 + 1 个观察项，可打卡回填；
3. **转奶计划引擎**：Gate 体检 → 逐日勺数配比 → 观测与判定 → 失败回退/冷却 → 全天切换；
4. **排敏调度器**：串行排期 + 与转奶/疫苗/生病窗口的冲突检测 + 高致敏食物分流；
5. **耐受维持与扩展**：已耐受食物维持提醒（每周 2-3 次）+ "下一步引入什么"的推荐清单；
6. **营养与成本账本 + 复诊摘要**：把长期坚持的收益（钱、食物种类、生长曲线）变成可见的回报，生成给医生的一页纸。

### 7.2 三条硬护栏（写入 PRD，不可协商）

| 护栏 | 规则 |
|---|---|
| **分型护栏** | 机制未知或为 IgE 介导（含混合型）时，**禁止输出任何家庭阶梯推进方案**，只能给知识科普 + 引导至专科；非 IgE 才可进入家庭阶梯流程 |
| **越界护栏** | 不诊断、不给药物剂量、不建议 OIT/生物制剂、不做"能不能吃"的最终裁定；所有阶次推进建议必须附"以医生评估为准"，并在高危信号出现时立即中断流程转向就医 |
| **节奏护栏** | 转奶期间不引入新辅食、不接种疫苗；观察期不足不判定；失败后强制冷却期（≥2 个月）不得提前重试 |

### 7.3 指标体系（用于验收，不只是埋点）

| 类别 | 指标 |
|---|---|
| 北极星 | 阶次推进率（进入下一阶的比例）、首次成功降阶所需天数 |
| 扩展 | 归一化后可摄入食材数（月净增）、耐受维持率（每周 ≥2 次暴露的比例） |
| 收益 | 月度奶粉支出下降金额、生长分位数趋势 |
| 安全 | 护栏漏报率、误报率、计划违规率（如转奶期新增辅食）、异常升级到就医的比例 |
| 依从 | 今日行动卡完成率、观察期打卡完成率、7 日回访留存 |

### 7.4 分期建议

| 期 | 内容 | 说明 |
|---|---|---|
| P0 | 机制分型字段 + 档案/里程碑 + 护栏 + 排敏归一化 + 转奶 Gate | 安全与地基，不做这些后面全是空中楼阁 |
| P1 | 转奶计划引擎（逐日任务）+ 回退/冷却 + 排敏调度冲突检测 + 今日行动卡 | 核心价值兑现 |
| P2 | 耐受维持 + 成本账本 + 复诊摘要 + 生长/营养缺口联动 | 长期粘性与"值回票价"的证明 |
| P3 | 主动推送（小程序订阅消息）、多智能体分工、依据真实数据的策略优化 | 需要 P0-P2 的数据积累才谈得上 |
