## 场景一：生成最近 7 天总结

### 原始回答的问题

1. 开头/结尾有流式拼接的重复话术（"好的，我已在为您生成…马上把完整总结发您～"），自相矛盾，破坏可信度
2. "数据口径""111 条记录"等运维术语，家长看不懂
3. "日均 800ml 要看月龄和生长曲线"说了等于没说，没有结论
4. 异常提示"偏差超 50%""前后均值"，系统化、家长看了焦虑不知该干嘛
5. 尿布/生长/表现/活动四个维度数据不足还逐个罗列，制造噪音
6. 结尾"免责声明 + 催促多记录"组合，观感差
7. 全程使用 emoji，不符合项目规范（No emojis）

### 改进样例（few-shot 候选）

```markdown
宝宝这一周整体状态很不错，吃奶规律、睡眠充足，没有需要特别担心的情况。

【吃奶】
宝宝平均每天喝约 800ml 配方奶，一天大概 7 次、每次约 110ml，节奏很规律，属于这个月龄宝宝的常见水平。

【睡眠】
平均每天睡约 12.2 小时，作息规律，睡眠是充足的。

【需要留意的一条记录】
8月17日那天睡眠只有约 4.4 小时，比平时少很多。可能是那天宝宝确实睡得少（比如不舒服、出门等），也可能是不小心记错了。需要的话，我可以帮您查一下那天的睡眠明细，看看是怎么回事。

想继续看某一天的情况，或者某一项的详细趋势，随时告诉我。
```

### 要点说明（供确认）

| 处理点 | 做法 |
|---|---|
| 拼接 bug | 开头直接进入主题，结尾自然收束，无"马上发您"式废话 |
| 术语降维 | "数据口径/111 条记录"→"一天大概 7 次" |
| 结论先行 | 第一句就给整体结论"状态很不错，没有需要担心的" |
| 粒度选择 | 只看日均（每天多少 ml、每天几小时），**不给周总量**（5610ml/85小时没人看） |
| 未填写不提醒 | 完全没填写的维度**不提醒**（母乳 0 条 → 就是纯配方奶，不用"如果平时有亲喂记得补"） |
| 数据不足不罗列 | 身高体重/尿布/活动等未填写或偏少的维度**直接不出现**，不逐个罗列"记录偏少" |
| 异常家长化 | 只保留真正对家长有意义的异常（8/17 睡眠），给"可能原因+我能帮你做什么" |
| 免责声明 | 从结尾移除（医疗敏感回答才需要，纯数据总结不需要） |
| emoji | 全部移除 |

## 场景二：帮我写今天的日记

### 原始回答的问题

1. 开头/结尾流式拼接话术（"马上为您写出今天的日记～"）
2. 日记是"数据流水账"（时间+毫升、时间段+分钟），不是"日记"
3. 暴露系统能力缺陷："系统显示今天共有 5 条喂养记录，但明细里只展开了 3 笔"——家长会问"为什么不全给我？"
4. 时间戳堆砌（20:53 / 00:00–01:14 / 01:20–05:03 / 05:40–06:38 / 09:58–11:54），老人看头晕
5. 无情感、无画面感，妈妈看完不想保存
6. 结尾"催记录"式收尾
7. emoji 不符合项目规范

### 改进样例（few-shot 候选）

```markdown
今天是 8 月 24 日，宝宝的一天过得很平稳，吃奶和睡觉都很有规律，是个让人省心的日子。

夜里宝宝 20:53 就睡着了，安安静静睡过零点。凌晨 1 点 20 分到 5 点 03 分睡了一大觉，差不多 3 个半小时，睡得挺香。早上 5 点 40 醒来玩了一会儿，又小睡了 1 小时左右。上午 9 点 58 分到 11 点 54 分，宝宝又睡了差不多 2 个小时，白天的小觉也接得不错。整体来看，宝宝夜里睡整觉、白天睡小觉，作息很有规律。

吃奶方面，今天记到了 3 次配方奶，分别在凌晨 1 点 18 分、清晨 5 点 12 分和上午 9 点 08 分，每次 150ml，间隔和量都很稳定。

愿宝宝明天也睡得香、吃得香。
```

### 要点说明（供确认）

| 处理点 | 做法 |
|---|---|
| 拼接 bug | 开头一句带入"宝宝的一天"，结尾一句温暖收束 |
| 叙事化 | 时间线翻译成"夜里睡整觉、白天睡小觉"的画面，不堆时间戳 |
| 未填写不提醒 | 照片未上传 → 不提"记得传照片"；母乳未记录 → 不提"有亲喂记得补" |
| 不催补记录 | 不说"系统还有 2 次喂养没展开，方便的话补一下"——不把记录义务推给家长 |
| 情感温度 | "让人省心的日子""睡得挺香""愿宝宝明天也睡得香" |
| 可保存性 | 日记读起来像一段可以保存的文字，而非报表 |
| 结尾 | 贴心话收尾，不是"催记录" |
| emoji | 全部移除 |
