## 1. 模块背景与目标

公众号 CMPA 科普是单向输出，家长遇到具体问题（"我家这种情况该喝什么配方"）无法即时获得针对性解答。本模块提供**检索增强的知识问答**：模型先检索知识库、基于检索结果作答、标注来源、未收录时明示。

**目标**：
1. 回答有依据（检索先行，不靠模型记忆编造）；
2. 来源可追溯（公众号文章/指南条目）；
3. 未收录不硬答（引导咨询医生）。

## 3. 覆盖故事与业务规则（US-02）

1. **前置条件**：会话已建立；知识库已导入（P1 范围：公众号 8 篇 + 核心指南 3-4 份）。
2. **Happy Path**：
   - 用户提问（如"深度水解和氨基酸配方怎么选"）；
   - 智能体**必须先行检索知识库**（检索先行规则），拿到结果后直接作答，禁止"正在检索/请稍候"话术；
   - 回答基于检索结果组织，末尾**标注来源**（文章标题/指南名），来源可点击展开详情；
   - 涉及医疗判断附免责声明。
3. **异常处理**：
   - 未检索到 → "知识库未收录，建议咨询医生"，不编造；
   - 检索超时/服务异常 → 提示稍后重试，不返回半截回答；
   - 涉及用药剂量/急救操作 → 拒绝给具体操作，引导就医；
   - 超出育儿护理范围 → 说明能力边界。

## 5. 验收标准

- **场景1: 命中**：知识库收录"深度水解/氨基酸" → 问"怎么选" → 给出 eHF/AAF 定位区别 + 来源标注；
- **场景2: 未收录**：问未收录主题 → "知识库未收录，建议咨询医生"，不编造；
- **场景3: 检索先行**：知识类问题回答中不出现"正在检索/请稍候"延迟话术；
- **场景4: 医疗边界**：问用药剂量/急救 → 拒绝给具体操作并引导就医；
- **场景5: 召回门槛**：50 题召回测试集 Recall@10 ≥ 90%（上线闸门）。
