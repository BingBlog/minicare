# M3 · 健康数据查询与家庭共享（产品方案）

> 模块：M3 ｜ 对应故事：US-04（自然语言数据查询）、US-05（多成员家庭共享与隔离）
> 上级文档：[PRD-003](../prd/PRD-003.md) ｜ [TECH-006 v2.0](../tech/TECH-006-minicare-agent-plan.md)
> 状态：规划中 ｜ 优先级：P2

## 1. 模块背景与目标

健康记录已积累（喂养/睡眠/尿布/生长/症状等），但家长难以自行解读"这周奶量正常吗"。本模块让用户**用日常语言查询自家宝宝的真实记录**，得到数字结论 + 数据来源说明，并保证多成员可共用、跨家庭不可见。

**目标**：
1. 自然语言 → 时间窗 + 指标 → 真实数据聚合；
2. 回答说明数据来源（统计口径），不编造；
3. 同家庭多成员可查询同一宝宝；跨家庭越权被拒。

## 2. 覆盖故事与业务规则

### 2.1 数据查询（US-04）

1. **前置条件**：会话绑定 babyId；该宝宝存在对应类型记录。
2. **Happy Path**：
   - 用户提问（如"旺仔上周平均每天喝多少奶""最近一周睡得好吗"）；
   - 智能体识别为数据类 → 解析时间窗（"上周"/"最近一周"=近 7 天，支持 1-90 天）与指标（喂养/睡眠/尿布/生长/健康/症状/活动）；
   - 读取真实记录聚合（总量/日均/次数/趋势）；
   - 回答给出数值结论 + **数据来源说明**（如"数据来自 6/1-6/7 的 42 条喂养记录"）。
3. **异常处理**：
   - 时间窗无记录 → "该时段暂无 xx 记录，建议先记录几天再来看"；
   - 时间窗超 90 天 → 按 90 天上限处理并说明；<1 天按当天；
   - 指标无法识别 → 引导明确类型（"您想查喂养、睡眠还是大便情况？"）；
   - 只读保障：任何情况下不能写入/修改记录（本期无写能力）。

### 2.2 家庭共享与隔离（US-05）

1. **前置条件**：提问成员已加入宝宝所在家庭组，宝宝档案对该成员可见。
2. **Happy Path**：奶奶登录自己账号 → 选择宝宝 → 提问 → 校验通过后正常回答，数据口径与主账号一致。
3. **异常处理**：
   - 成员不属于该家庭/宝宝不可见 → 拒绝并提示无权限（不泄露数据存在性细节）；
   - 伪造 babyId/家庭信息 → 服务端校验拒绝，记录审计日志。

## 3. 页面交互（数据来源说明条）

```text
┌──────────────────────────────────────────────┐
│  [数据] 统计口径: 6/1-6/7 (7天)              │
│        喂养记录 42 条 · 日均 780ml           │
│        数据来自宝宝的喂养记录，仅统计该时段   │
└──────────────────────────────────────────────┘
```

## 4. 验收标准

- **场景1: 喂养聚合**：近 7 天 42 条（5460ml）→ 问"上周平均每天喝多少奶" → "平均约 780ml/天" + 数据来源与统计口径；
- **场景2: 空数据**：无睡眠记录 → "该时段暂无睡眠记录" + 引导记录，不编造；
- **场景3: 数据隔离**：会话绑定宝宝 A → 任何查询只引用宝宝 A 记录；
- **场景4: 同家庭多成员**：奶奶问睡眠 → 正常返回聚合 + 数据来源；
- **场景5: 跨家庭越权**：用户 A 查宝宝 X（非同家庭）→ 拒绝，不返回数据。
