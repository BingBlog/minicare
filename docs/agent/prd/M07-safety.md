# M7 · 安全护栏与反馈闭环（产品方案）

> 模块：M7 ｜ 对应故事：US-11（风险分级护栏）、US-12（回答反馈闭环）
> 上级文档：[PRD-003](../prd/PRD-003.md) ｜ [TECH-006 v2.0](../tech/TECH-006-minicare-agent-plan.md)
> 状态：规划中 ｜ 优先级：P0（护栏横切）/ P4（反馈闭环）

## 1. 模块背景与目标

AI 健康助手的底线是**不延误就医、不误导家长**。本模块提供横切全对话的风险分级护栏（low/caution/emergency）+ 固定免责机制，以及回答反馈闭环（不准确回流修订）。

**目标**：
1. 高危信号 → 强制就医引导，绝不安抚；
2. 症状判断 → 明确分级（观察清单 vs 就医指征）；
3. 所有医疗类回答附免责声明；
4. 用户反馈回流，内容持续改进。

## 2. 覆盖故事与业务规则

### 2.1 风险分级护栏（US-11）

1. **前置条件**：无（全局横切，所有对话生效）。
2. **两条触发路径**：
   - **被动拦截**：描述命中高危信号（大量鲜血便/精神萎靡/持续高热/呼吸急促/抽搐等，或知识库命中 emergency 条目）→ 立即输出**就医引导卡片**，停止常规安抚；
   - **主动咨询**：描述自己观察到/已记录的症状并询问严重程度（"宝宝今天大便有血丝，要不要去医院"）→ 按知识库分级：caution → 观察要点 + 就医指征清单；emergency → 就医引导。
3. **就医引导内容**：明确"需要尽快就医"、建议尽快就诊、就诊携带近期记录；不给出诊断或治疗方案。
4. **免责**：涉及医疗判断的回答尾部附"本回答仅供参考，不能替代专业医疗建议"。
5. **异常处理**：
   - 含高危词但语气不确定 → 按高危处理（宁可引导就医，不冒险安抚）；
   - 症状较轻但反复追问 → 给观察清单 + 明确就医指征，不代替医生下结论；
   - 追问"你觉得严不严重" → 不代替医生判断，重复引导/清单。

### 2.2 回答反馈闭环（US-12）

1. **前置条件**：存在至少一条助手回答。
2. **Happy Path**：每条回答尾部反馈入口（有帮助/不准确/不相关）→ 点"不准确"→ 可选留一句话 → 提交"感谢反馈"；
3. **回流（P4）**：反馈按周汇总，标记"不准确"的回答回流知识库修订流程（同一问题 ≥N 次标记 → 进修订清单）。
4. **异常**：提交失败静默/轻提示；反馈仅存标签 + 可选文本，不涉及对话外个人信息。

## 3. 页面交互（就医引导卡片 + 反馈条）

```text
就医引导卡片（emergency）                       反馈条（每条回答尾部）
┌──────────────────────────────────┐   ┌──────────────────────────────┐
│ [!] 您描述的「便血+精神不好」     │   │ 这条回答对你有帮助吗？        │
│     需要尽快就医                  │   │  [有帮助] [不准确] [不相关]  │
│ · 请停止线上咨询，尽快带宝宝       │   └──────────────────────────────┘
│   前往医院                        │   （点"不准确"→ 确认弹窗，可留一句话）
│ · 就诊时携带近期健康记录          │
│ · 就医途中注意观察宝宝状态        │
│ 本回答仅供参考，不能替代专业      │
│ 医疗建议                          │
└──────────────────────────────────┘
```

## 4. 验收标准

- **场景1: emergency 强制就医**：描述"便血很多+没精神" → 就医引导为主，**不**出现"先观察几天"；
- **场景2: caution 观察清单**："少量血丝但精神好" → 观察要点 + "以下情况需立即就医"清单 + 免责；
- **场景3: 主动咨询分级**：问"要不要去医院" → 按症状分级给观察/就医建议，不强行要求就医也不安抚拖延；
- **场景4: 高护栏覆盖**：任意会话命中高危词 → 无论上下文如何都触发就医引导；
- **场景5: 反馈提交**：点"不准确"确认 → "感谢反馈"，该回答标记待修订；
- **场景6: 反馈回流（P4）**：同一问题 ≥N 次"不准确" → 进修订清单。
