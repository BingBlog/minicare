# M4 · 总结分析与生长曲线（产品方案）

> 模块：M4 ｜ 对应故事：US-06（单维趋势解读）、US-07（跨维综合总结）
> 上级文档：[PRD-003](../prd/PRD-003.md) ｜ [TECH-006 v2.0](../tech/TECH-006-minicare-agent-plan.md)
> 状态：规划中 ｜ 优先级：P2

## 1. 模块背景与目标

家长不只想知道数字，还想知道"趋势怎么看""整体情况如何"。本模块提供**数据驱动的总结分析**：单维趋势解读 + 跨维度综合总结 + 生长曲线百分位，支持对话内显式请求与**一键周报/月报**快捷触发。总结分析可单独回答，也可作为每日日记（M5）的内容素材。

**目标**：
1. 趋势/规律解读带数据依据，异常点明确提示；
2. 跨维总结结构化（各维度小结 + 关注点）；
3. 生长维度给出百分位对照（P50/P75，中国 2023 参考数据）。

## 2. 覆盖故事与业务规则

### 2.1 单维趋势解读（US-06）

1. **前置条件**：绑定 babyId；时间窗内有效记录 ≥5 天。
2. **Happy Path**：用户请求（如"最近两周奶量趋势怎么样""这周睡眠规律吗"）→ 按天聚合序列 → 识别趋势（上升/下降/稳定/波动）与异常点 → 回答 = 趋势结论 + 关键数字 + 异常点提示 + 数据依据。
3. **异常处理**：
   - 有效记录 <5 天 → "记录还不足以分析趋势，建议再记录几天"；
   - 数据稀疏（中间缺天）→ 按实际记录天数说明口径，不补全；
   - 疑似误录（单日数值异常大/小）→ 标注"请确认是否误录"。

### 2.2 跨维综合总结（US-07）

1. **前置条件**：绑定 babyId；时间窗内至少 2 个维度有记录。
2. **Happy Path**：
   - 触发方式两种：对话请求（"这个月旺仔整体情况如何"）或**对话页「一键周报/月报」按钮**（按 7/30 天窗口）；
   - 跨维度读取记录（喂养/睡眠/生长/症状/尿布/活动）逐维生成小结；
   - 输出**结构化总结卡片**：各维度小结（关键数字）+ 规律/变化 + 异常关注点 + 数据依据；
   - 生长维度含**生长曲线解读**（体重/身高 P50/P75 等百分位，内置中国 2023 儿科生长参考数据）；
   - 关注点结合知识库给建议。
3. **异常处理**：
   - 数据极少（<2 维度有记录）→ 提示记录不足，展示已有维度；
   - 某维度无记录 → 标注"暂无记录"，不编造；
   - 总结含异常 → 走风险分级（M7）：emergency 直接就医引导。

## 4. 验收标准

- **场景1: 趋势分析**：14 天完整喂养记录 → "最近两周奶量趋势" → 趋势结论（含 6/15 回落）+ 数据依据；
- **场景2: 数据不足**：仅 2 条睡眠记录 → 提示记录不足，说明当前仅 2 条；
- **场景3: 跨维总结**：7 月多维记录 → "7 月整体情况" → 结构化卡片 + 生长 P50-P75 + 关注点 + 数据依据；
- **场景4: 一键周报/月报**：点「周报」→ 输出最近 7 天总结卡片（同场景 3 逻辑，7 天窗口）；
- **场景5: 维度缺数据**：只有喂养记录 → 其余维度"暂无记录"，不编造。
