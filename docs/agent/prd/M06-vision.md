# M6 · 图片问诊（产品方案）

> 模块：M6 ｜ 对应故事：US-03（上传宝宝照片获得分级判断）
> 上级文档：[PRD-003](../prd/PRD-003.md) ｜ [TECH-006 v2.0](../tech/TECH-006-minicare-agent-plan.md)
> 状态：规划中 ｜ 优先级：P0（视觉链路实测）/ P3（UI）

## 1. 模块背景与目标

文字描述症状不直观（"大腿上的红疹"说不清范围/形态）。本模块支持家长**上传宝宝照片（皮疹/大便/伤口等）+ 文字**，AI 看图后结合知识库给出分级判断（正常/观察/就医）。

**目标**：
1. 拍图即问，比文字更直观；
2. 看图解读 + 知识库 + 风险分级（观察还是就医）；
3. 无法解读时诚实降级，不编造。

## 2. 覆盖故事与业务规则（US-03）

1. **前置条件**：会话已建立；图片 jpg/png（拍照/相册），压缩后 ≤10MB/张、每轮 ≤3 张。
2. **Happy Path**：
   - 输入区点图片 → 拍照/相册选图（可附文字问题）→ 压缩上传 → 随文字发送；
   - AI 解读图片内容（视觉模型 deepseek-v4-flash-vision-exp）+ 知识库 → 分级判断：正常 / 观察要点 / 就医引导（走 M7 护栏规则）；
   - 回答附免责声明；
   - 对话中上传的图片自动成为当天日记素材（M5）。
3. **异常处理**：
   - 上传失败 → 提示重试，文字仍可发送；
   - 图片无法解读（模糊/不相关部位/光线差）→ 明确"图片无法判断" + 引导补充文字描述（部位/时长/大小）；
   - 视觉模型不可用 → 降级纯文字回答 + 提示"图片暂无法识别，请用文字描述症状"；
   - 超限（>3 张 / >10MB）→ 拒绝并提示。

## 4. 验收标准

- **场景1: 图片问诊**：上传皮疹照片 + "这是过敏吗" → AI 结合图片与知识库给分级判断 + 免责；
- **场景2: 无法解读**：模糊照片 → "图片无法判断" + 引导文字描述，不编造；
- **场景3: 降级**：视觉模型不可用 → 纯文字对话 + 提示；
- **场景4: 超限**：>3 张 / >10MB → 拒绝并提示；
- **场景5: 素材联动**：对话图片进入当天日记素材（M5 验证）。
