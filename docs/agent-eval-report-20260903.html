给 agent 的改进清单

  • 多工具组合耗时：数据+知识库双工具链路 60~76s。生产代理 60s 超时内吃不到这份能力——要么代理层放宽超时，要么做工具并行 / 知识库检索提速。
  • 过度知识库调用：R1-07「大便正常吗」自行追加 search_knowledge（数据问题以数据回答为主即可），在 55s 预算下直接导致截断。
  • 免责声明覆盖：涉及健康判断（睡眠充足、体重正常）的回答偶发缺「必要时咨询医生」类声明（R1-20 style 0.3）。
  • 运维话术残留：偶发「后台/同步/数据返回」表述（R1-13），与「家长语言」人设有冲突。
