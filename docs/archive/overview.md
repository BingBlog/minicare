# 敏宝日记 · 产品概述

> 最后更新：2026-05-03（MVP 已完成，小程序已发布）

## 1.1 产品定位与目标

**敏宝日记**是一款专为 0-1 岁牛奶蛋白过敏（CMPA）宝宝家庭打造的饮食生活记录和健康管理工具。产品定位为「**敏宝家庭的结构化健康记录工具**」，核心目标是帮助照护者把饮食、表现、生长发育等信息**系统化记录并导出**，方便就医时携带与沟通。

**分发平台**：以**微信小程序**为主要分发渠道（AppID: `wxac792556967d5838`）。选择小程序的核心原因是：无需安装、微信生态内分享传播便捷、家庭成员协作零门槛。Web 端作为早期原型开发平台保留，处于维护模式。

**MVP 状态**：已完成开发并在微信小程序平台发布。核心特性包括：家庭多成员共享（支持多人同步记录和查看同一宝宝数据）、云端数据同步、8 类护理记录、数据分析报告。

## 1.2 目标用户群体

**核心用户（父母）**：25-35 岁，本科及以上学历，一线城市敏宝父母；需要多成员协作记录。

**协作用户（祖辈/保姆）**：50-65 岁；需要简单易用的记录工具；微信小程序免安装的特性天然降低了使用门槛。

## 1.3 核心价值主张

**全场景记录**：涵盖饮食（配方奶/母乳/辅食/营养素）、睡眠、活动、尿布、健康、表现、生长、医疗等敏宝护理全场景，共 8 大记录类型。

**结构化管理**：符合医学记录标准，数据分析报告支持 5 个维度（饮食/尿布/生长/睡眠/健康）的图表可视化。

**家庭协作**：通过手机号邀请家庭成员，多人实时同步记录同一宝宝的护理数据。

**零门槛使用**：微信小程序无需下载安装，扫码即用；自定义 TabBar + FAB 快捷入口，3 次点击内到达任何核心功能。

## 1.4 产品边界（MVP 已实现）

**已完成功能**：

P0 级核心功能全部上线：手机号验证码登录/注册、宝宝档案管理（含过敏原）、家庭共享与多成员协作（手机号邀请）、8 类日常记录（饮食/睡眠/活动/尿布/健康/表现/生长/医疗）、今日概览首页（统计卡片+时间线）、数据分析报告（5 维度 ECharts 图表）、游客预览模式。

**后续迭代方向**：AI 分析与建议、社区功能、PDF 报告导出与分享、推送通知与提醒、激励机制与会员体系。

## 2.2 信息架构与导航

**底部 Tab（4 个）+ 中心 FAB 按钮**：

| Tab | 定位 | 主要内容 |
| -------- | ------------------ | -------------------------------------------------------------------- |
| **首页** | 今日概览与快捷入口 | 今日统计卡片（奶量/睡眠/尿布/表现）、进行中睡眠 Banner、最近喂食 Banner、今日时间线、FAB 快捷记录入口 |
| **记录** | 全部记录浏览 | 按日期分组的全类型记录列表，支持编辑/删除 |
| **统计** | 数据分析报告 | 5 个 Tab（饮食/尿布/生长/睡眠/健康），ECharts 图表，支持多时间范围切换 |
| **我的** | 档案与设置 | 宝宝档案（头像/名字/过敏信息）、生长数据、家庭成员管理、退出登录 |

**中心 FAB 按钮**：点击弹出 FabSheet，分组展示所有 8 种记录类型的快捷入口。

**分包加载策略**：主包仅含 4 个 TabBar 页面，登录/引导/隐私政策/8 种记录表单页面全部放在 subPackages 中按需加载，优化首屏体积。

## 2.3 全局状态与关键规则

**当前宝宝**：MVP 阶段每个家庭限 1 个宝宝，无需切换。后续支持多宝宝时增加选择器。

**时间基准**：记录以用户选择的「发生时间」为准；补录时默认当前时间，可改为历史时间。

**今日定义**：以自然日 0:00-24:00（东八区 UTC+8）聚合首页「今日」统计。

**游客模式**：未登录用户可预览首页功能布局，点击任何记录操作时引导登录。
