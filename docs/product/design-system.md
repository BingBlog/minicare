# 视觉设计与交互规范

> 来源：docs/business/MVP-PRD.md §4、§8.5  
> 最后同步：2026-03-29

## 视觉设计原则

**设计风格**：暖粉色系卡通亲切风格，主色调玫瑰粉（#F87098），配合薄荷绿、暖黄、柔紫等辅助色，营造温馨、专业、易用的视觉体验。界面整体采用圆角卡片式布局，字体偏圆润。

## 色彩规范

```css
/* 主色 */
--primary: #f87098;      /* 玫瑰粉，按钮/激活/强调 */
--primary-lt: #fff0f4;   /* 极浅粉，图标背景/选中态背景 */
--primary-md: #f8b8cc;   /* 中粉，描边/次要 */

/* 功能色 */
--green: #4caf82;        /* 睡眠/成功状态/正向反馈 */
--warm-yellow: #ddb870;  /* 活动/警告提示 */
--purple: #9b8ed8;       /* 生长/数据图表 */
--warning-red: #e8507a;  /* 过敏提示/危险操作 */

/* 文字 */
--text: #3d2b2e;         /* 主文字，暖棕灰 */
--sub-text: #9a7e82;     /* 次级文字，暖灰 */

/* 背景 */
--bg: #fdf7f5;           /* 页面背景，暖白 */
--card-bg: #ffffff;      /* 卡片背景 */
```

## 字体规范

- 系统字体：SF Pro（iOS）/ Roboto（Android）
- 一级标题：18-20pt，Bold（700）
- 二级标题：15-16pt，SemiBold（600）
- 正文内容：14pt，Regular（400）
- 辅助说明：12pt，Regular（400）
- 行高：1.5-1.6 倍行高

**大字体模式**：字体大小一键切换至 20pt 以上，立即生效，无需重启。

## 图标规范

**图标库**：采用 **Lucide Icons**（开源，SVG 格式，stroke 风格），不使用 emoji 替代功能性图标

**全站图标化**：所有原使用 emoji 的功能性场景（警告提示、操作按钮、类型选择等）均替换为对应的 SVG 图标

### 颜色控制（关键！）

```css
/* ✅ 正确：通过 color 控制，走 currentColor 继承 */
.icon-box .icon { color: #f0b8c8; }

/* ❌ 错误：stroke 对 <use> 引用的 symbol 无效 */
.icon-box .icon { stroke: #f0b8c8; }
```

## 导航设计

**底部 Tab 导航**：
- 4 个 Tab：首页 / 记录 / 报告 / 我的
- 高度：49pt（标准），图标与文字结合显示
- 未激活：浅粉图标（#F0B8C8）；激活：深粉图标（#E8507A）

**页面层级**：
- 核心功能不超过 3 级
- 主要操作路径不超过 3 次点击
- 复杂操作采用模态弹窗或新页面

## 交互原则

1. **认知减负**：单个界面核心功能不超过 5 个
2. **操作简化**：核心操作不超过 2 步，减少键盘输入
3. **渐进式披露**：次要功能通过二级界面展开
4. **视觉层级明确**：通过字号、色阶区分信息优先级

**触控目标**：
- 核心功能图标直径不小于 72dp
- 按钮高度不低于 44dp
- 大字体模式（可一键切换）

## 输入方式设计

所有涉及内容录入的功能均同时提供以下五种输入方式：
1. **手动输入**：标准文本输入框，支持自动完成和纠错
2. **自然语言输入**：口语化文字描述 → 系统解析为结构化字段 → 解析确认卡片 → 确认保存
3. **语音输入**：按住麦克风 → 语音转文字 → 走自然语言解析流程
4. **拍照/图片输入**：
   - OCR 文字提取（**仅限医疗记录模块**）
   - 纯图片留档（**其他所有模块**，不做 OCR）
5. **选项/快捷选择**：预设选项（奶量快选、情绪图标、表现勾选等）

**智能解析确认机制**（适用于自然语言输入、语音输入、医疗记录 OCR）：
