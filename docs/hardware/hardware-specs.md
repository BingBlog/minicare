# 硬件规格说明

## 一、硬件资源

设备外观包含以下接口与组件：

- **摄像头**：GC0308
- **扬声器喇叭**
- **GH1.25-5P 扩展接口**：支持 GPIO / UART / CAN / PWM
- **GH1.25-5P 扩展接口（I2C）**
- **麦克风 1 输入口**
- **复位按键**
- **自定义按键**
- **2.0 寸 IPS 液晶屏**：电容触摸，分辨率 240×320
- **麦克风 2 输入口**
- **Type-C 接口 / USB OTG 接口**：用于供电、程序下载、串口调试以及 USB 通信
- **Micro SD 卡接口**
- **电池包 Type-C 接口**
- **电源按键**

## 二、硬件特点

- 高清摄像头（200 万像素），支持拍照识别，生动形象描述照片
- 完整音频系统，麦克风输入（双麦克风）和喇叭输出
- 支持 Wi-Fi / Bluetooth，物联网应用更丰富
- 2.0 寸 IPS 高清彩色液晶屏，可用作各种显示应用
- 电容式触摸屏，可实现手指控制应用
- 精致小巧，无螺丝设计，易于拆装
