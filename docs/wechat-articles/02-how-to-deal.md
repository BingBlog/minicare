# 牛奶蛋白过敏要如何应对

上一篇聊完什么是牛奶蛋白过敏，后台收到最多的一个问题就是，那我该怎么办。

焦虑，自责，迷茫，这三种情绪混在一起，我太理解了。是不是我孕期吃错了什么，换奶粉就行了吗，会不会一辈子都这样，脑子里全是问号。

说实话，这些反应特别正常。因为你不知道接下来要面对什么，不确定性才是最大的焦虑来源。

那今天就来消除这种不确定性。

先搞清楚一件事，你的宝宝到底有没有牛奶蛋白过敏的信号。

这个病的症状特别狡猾，它可以表现在皮肤上，湿疹反复发作怎么涂药都不好，荨麻疹说来就来，吃奶后嘴巴周围一圈红肿。也可以表现在肚子里，吐奶，腹泻，便便带黏液甚至血丝，吃几口就扭头不吃了，肚子鼓鼓的老放屁。还可以表现在呼吸道，喘息，慢性咳嗽，没感冒也老堵鼻子。还有一些全身性的信号，体重增长慢，生长曲线往下掉，烦躁哭闹，夜醒频繁。

你想想看，如果宝宝同时有湿疹和腹泻，你很可能分别去看皮肤科和消化科，拿到两套完全不搭的诊断和方案。但根源其实是同一件事。

所以如果你的宝宝出现了两项及以上的上述表现，尤其是消化道加皮肤的组合，请认真考虑CMPA的可能。

好，假设你已经开始怀疑了，接下来最重要的一步是什么？

不是换奶粉。

不是上网查。

是去看医生。

这一点我真的要强调，请不要自行下结论，也不要自行换奶。CMPA的症状和乳糖不耐受、肠套叠、感染性腹泻、胃食管反流都能撞脸，你自己很难分辨，搞错了方向可能越治越糟。

挂什么科呢，儿科是最基本的，如果当地医院有小儿消化科，首选这个，过敏科或者变态反应科也可以。

到了医院，医生怎么查呢？先别急着想抽血的事，医生最看重的其实是跟你聊天。

喂养方式，症状什么时候开始的，症状和吃奶有没有关系，家里有没有过敏史。很多人觉得问诊不算检查，但在CMPA的诊断里，一份详细的病史比任何化验单都有价值。你把细节说清楚，医生心里就有数了。

聊完之后，检查走两条路。

上一篇聊过，牛奶蛋白过敏分速发型和迟发型。这两种的检查方式完全不一样，你得搞清楚你宝宝是哪种，不然白查。

速发型，就是吃下去很快就有反应的那种，可以做皮肤点刺，把微量过敏原滴在皮肤上轻轻刺一下，15到20分钟看反应。也可以抽血查过敏抗体。这两种检查对速发型都管用，能查出来。

但迟发型，就是吃下去几个小时甚至几天才发作的那种，这两种检查统统查不出来。

那怎么办？用排除法。先把牛奶蛋白停掉2到4周，看症状有没有改善。改善了，再在医生监护下重新引入，看会不会复发。好转了又复发了，就确认了。

这个方法听起来绕，但它就是迟发型的确诊标准。

说到这块，有个特别容易踩的坑。很多家长拿着阴性结果的过敏原报告，觉得查了都不过敏，就直接排除了CMPA。但你想想，速发型的检查去查迟发型的问题，就像用体温计去量血压，量不出来就说没高血压，这个逻辑对吗？

所以如果你的宝宝症状就在那里，但过敏原检测全阴性，不要轻易说不是过敏，跟医生充分沟通，考虑做排除试验。

好，确诊了或者高度怀疑了，接下来就是最核心的一步，饮食管理。

这块分三种情况。

如果你家宝宝是母乳喂养的，继续喂，不要轻易断母乳。母乳是过敏宝宝最好的食物，这一点在所有国际指南里都是一致的。但妈妈需要做出调整，严格回避牛奶和所有奶制品，牛奶，酸奶，奶酪，黄油，含乳的面包饼干蛋糕，通通停掉。很多加工食品里藏着牛奶蛋白，沙拉酱，巧克力，甚至某些药品的辅料也含乳糖，买之前养成翻配料表的习惯。

妈妈回避2到4周观察宝宝症状有没有改善。同时别忘了给自己补钙，每天1000毫克，再加适量维生素D，因为你把奶制品全停了，钙的摄入会大幅下降。

母乳里的微量牛奶蛋白可能需要几天才能完全清除，所以别急，给身体一两周的清除时间。

如果你家宝宝是配方奶喂养的，根据过敏严重程度选替代配方。轻中度的用深度水解配方，蛋白质被深度分解，致敏性极低。重度的用氨基酸配方，蛋白质被完全拆成最基本的氨基酸，零致敏性。换奶后2到4周评估效果。

具体怎么选，我会在第4篇详细讲，别急。

如果宝宝已经加辅食了，所有含牛奶蛋白的辅食都得停，面包饼干蛋糕酸奶奶酪这些最常见。还要学会看配料表，牛奶蛋白可能披着这些马甲出现，乳粉，脱脂乳粉，乳清蛋白，酪蛋白，奶油，乳固体。还有一点，6个月以下的宝宝不要用豆奶替代。

饮食管理是治本，日常护理是治标，让宝宝舒服一些。

湿疹的宝宝，保湿霜足量多次，每天3到5次起步，湿疹的地方厚涂，别省。穿衣比大人少一件，别捂着。洗澡水温32到37度，别烫，洗10分钟就够。选无香精的沐浴露和润肤霜，带香味的可能刺激皮肤。

吐奶的宝宝，少量多餐，吃完竖抱拍嗝15到20分钟。顺时针揉揉肚子，轻一点就行。

还有一件很容易被忽略的事，情绪安抚。过敏宝宝经常因为不舒服而烦躁哭闹，这不是脾气大，是真的难受。白噪音，轻轻摇晃，贴身抱着宝宝，都有帮助。照顾一个不舒服的宝宝确实很累，我有时候也觉得快撑不住了，但请记住这不是永久的。

最后聊一个几乎所有家长都最关心的问题，过敏会好吗？

会。

约50%的宝宝1岁前就能耐受牛奶蛋白，75%在2岁前，80%到90%在3岁前脱敏。

但耐受不是干等来的。

需要定期复查，6到12个月做一次口服食物激发试验，评估宝宝是否建立了耐受。耐受建立后，可以通过牛奶阶梯法逐步引入，从低致敏性的烘焙食物开始，一步步升级到鲜牛奶。每次激发试验必须在医疗机构进行，尤其是速发型的宝宝，有严重过敏反应的风险，不能在家自己做。

说到这块，有几个流传特别广的误区，不聊不行。

第一个，换羊奶就行。羊奶和牛奶蛋白的交叉过敏率超过90%，对牛奶蛋白过敏的宝宝大概率对羊奶也过敏。换羊奶不是解决办法，只是换了一种蛋白来过敏。

第二个，豆奶可以替代。部分宝宝对大豆也过敏，交叉过敏率10%到35%，而且豆奶不适合6个月以下的宝宝。能不能用豆奶，得医生说了算。

第三个，过敏长大就好了不用管。这话对了一半，大多数宝宝确实会自然耐受。但不干预的期间，持续的过敏反应在影响生长发育，在推动过敏进程。上一篇聊过多米诺骨牌对吧，长大就好了不等于现在不用管，第一张牌不拦，后面哗啦啦全倒。

第四个，水解奶粉营养不够。特殊医学配方的营养成分是完整的，水解只是改变了蛋白质的大小，不影响营养价值。就像把一块牛排切成肉丝，营养没变，只是形态变了。

回过头来看，应对牛奶蛋白过敏，其实就是五件事，识别信号，就医确诊，饮食管理，日常护理，定期复查。没有哪一步特别难，但每一步都得做对。

这条路不长，但需要耐心。大多数宝宝1到3岁就能告别牛奶蛋白过敏，前提是科学管理，规范随访。
