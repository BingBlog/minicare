# 宝宝便血了，先别慌

换尿布的时候，你看到纸尿裤上有血丝。

那一瞬间，心跳加速，手开始发抖，脑子里闪过无数可怕的可能。

深呼吸。

先告诉你一个事实，几个月大的宝宝便血，最常见的原因不是什么可怕的病，而是牛奶蛋白过敏。听起来吓人，但它可诊断，可治疗，预后良好。关键就四个字，正确识别。

不过在那之前，有一件事必须先说清楚。有些便血是急症，不能等。

大量鲜血，不是血丝，是明显的鲜血。伴随面色苍白、精神萎靡、反应差。呕吐胆汁样物，绿色的。腹部摸到包块，或者宝宝一阵一阵地剧烈哭闹，哭一阵停一阵。发热加上便血。

以上任何一条，立刻去医院急诊，不要再往下看了。

好，排除完了，宝宝精神状态还可以，只是大便里偶尔有血丝或者血点，那我们继续聊。

便血的原因其实不少，不是所有便血都是牛奶蛋白过敏。但牛奶蛋白过敏确实是最常见的那一个，大概占了40%到50%。

怎么区分呢？不同原因的便血，血的样子和伴随症状不一样。学会初步辨别，跟医生沟通的时候能省不少事。

牛奶蛋白过敏的便血，血和黏液混在便便里面，不是光附在表面。常伴有腹泻，大便偏稀，有黏液。通常是少量反复出现的血丝或血点，不是大量出血。可能同时有湿疹、吐奶、烦躁这些其他过敏表现。

还有一种常见的是肛裂。肛裂是因为便秘，大便太硬撑破了肛门皮肤。血是鲜红色的，附在便便表面或者擦的时候在纸巾上。宝宝排便的时候可能因为疼哭闹，但拉完就好了。最关键的区别是，肛裂的便便是干硬的，牛奶蛋白过敏的便便是稀的、带黏液的。

还有一个必须知道的，肠套叠。这个是6个月到2岁宝宝最需要紧急处理的急腹症。典型表现是果酱样大便，暗红色黏冻状的，加上一阵一阵地剧烈哭闹，加上呕吐。出现了这个，不要犹豫，立刻就医。

旺仔便血那段时间，我真的是每天换尿布都提心吊胆。看到纸尿裤上有红色，心就往下沉一截。后来学会了看血的样子，黏液混着的血丝和表面附着的鲜血，性质完全不一样。能分清楚之后，至少不那么慌了。

你可能觉得奇怪，为什么偏偏是几个月大的小宝宝容易便血？

这跟宝宝这个阶段的生理特点有关。几个月大的宝宝，肠道黏膜之间的紧密连接还没发育完善，通透性比成人高。大分子蛋白质容易穿过肠壁进入体内，被免疫系统识别为入侵者。加上免疫系统还处于学习阶段，免疫平衡偏向过敏那一侧，更容易产生过敏反应。还有一个因素，很多宝宝在出生后不久就接触了配方奶，可能是因为母乳不足、黄疸住院各种原因。早期大量接触牛奶蛋白，对还没成熟的免疫系统是一种强刺激。

典型的时间线是这样的。出生后2到8周开始出现症状，1到3个月达到高峰，便血最常见。4到6个月后，随着肠道和免疫系统逐渐成熟，症状趋于缓解。

旺仔差不多就是50天左右出现的便血，正好卡在那个高峰期。

如果你发现宝宝便血了，几件事要做。

第一，不要慌，先观察。血的颜色，鲜红还是暗红。血的量，少量血丝还是明显出血。血和便便的关系，混在一起还是只在表面。伴随症状，有没有发热、呕吐、精神差、阵发哭闹。

第二，拍下便便的照片。这个听起来不太好听，但非常实用。就诊的时候一张照片比「好像有点红」的文字描述准确太多了。如果方便，也可以保留带血的纸尿裤带给医生看。我当时就是每次都拍照，手机相册里全是旺仔的便便照片，但跟医生沟通的时候确实效率高了很多。

第三，及时就医。挂儿科或小儿消化科。告诉医生便血的颜色、量、频率，宝宝的喂养方式，有没有其他症状，家族过敏史。

第四，不要自行停奶或换奶。这块我们吃过亏。在医生指导下调整饮食，自己换可能换错，比如换成适度水解，对已经确诊的牛奶蛋白过敏无效。也可能营养摄入不足影响发育，还可能掩盖症状影响医生判断。

医生通常会怎么建议呢？母乳喂养的，妈妈回避牛奶蛋白2到4周。配方奶喂养的，换深度水解或者氨基酸配方。饮食排除之后观察便血有没有改善。

这里有个事情要注意。过敏原检测阴性不等于不是牛奶蛋白过敏。迟发型的过敏，抽血查特异性IgE抗体是查不出来的。这个在系列第二篇详细讲过，如果你家宝宝过敏原检测阴性但症状高度吻合，别轻易排除CMPA的可能。

还有一个很常见的误诊情况，被当成肠炎治。3个月的小宇，反复便血2周，大便中经常看到血丝和黏液，一天4到5次稀便。去了两家医院，第一家说是肠炎，开了抗生素，吃了5天没效果。第二家说是消化不良，让吃益生菌，也不见好。后来妈妈带小宇去了小儿消化科，医生详细问了喂养史，出生后因为黄疸住过院，期间吃过配方奶，出院后一直混合喂养。查了过敏原检测阴性，但医生结合症状高度怀疑CMPA。建议妈妈严格回避牛奶蛋白，配方奶部分换成深度水解。2周后复诊，便血消失了。

这个场景太典型了。CMPA便血特别容易被误诊为肠炎，然后反复用抗生素。但抗生素对过敏无效，反而可能进一步破坏肠道菌群，加重症状。如果你家宝宝反复便血，按肠炎治疗效果不好，请考虑CMPA的可能性。

好消息是，牛奶蛋白过敏引起的便血治疗效果通常很好。饮食干预后2到4周，便血明显减少。4到8周，便血完全消失。1到3岁，大概80%到90%的宝宝可以建立耐受，恢复正常饮食。

不必过度焦虑。CMPA便血看起来吓人，但它不是那种需要手术、需要长期住院的严重疾病。你需要的只是正确的诊断，正确的配方，以及一些耐心。

回过头看，便血只是牛奶蛋白过敏的冰山一角。但它是很多家长第一次意识到「宝宝可能过敏了」的那个触发点。就像我们，看到旺仔便血的那一刻，才真正开始认真对待这件事。

如果你正在经历这个阶段，记住这几件事。血和黏液混合伴腹泻，高度提示CMPA。过敏原检测阴性不等于不是CMPA。不要自行换奶，找小儿消化科或过敏科。饮食干预2到4周多数见效，1到3岁大多能耐受。
