# PRD 总集

用法约定：
- 每新增一个 PRD，就新增一行，给它一个固定的"版本号"（这里作为总集里的唯一标识，不再变）。
- 单个 PRD 文档内部如果需要迭代，用 `v0.1 / v0.2 / v1.0` 自己维护；总集这里不记录内部小版本。
- 历史追溯交给 Git，总集永远指向最新 PRD 链接。

| 版本 | 标题 | 需求内容（详细摘要） | PRD 链接 |
|---|---|---|---|
| PRD-001 | 语音录入功能 | 目标：让用户"说一句话即可完成记录"，大幅降低录入门槛。范围：长按语音按钮采集（上滑取消/太短提示）→ AI 识别记录类型与关键字段 → 半屏结果卡片确认/修改/取消；覆盖内容不匹配、字段不足、转写失败、服务异常等异常路径，均提供重试或手动录入引导。非目标：不做连续多段语音合成一条记录。 | docs/prd/PRD-001.md |
| PRD-002 | 辅食记录与排敏管理 | 目标：在辅食记录基础上新增"排敏任务化管理"，让用户直观看到每个食物的排敏进展与风险状态。范围：首次引入新食物自动创建观察任务（默认3天，可配置3-7天）→ 每日打卡推进 Day1/Day2/Day3 → 异常判定（轻中度标记疑似暂停观察、严重标记确认过敏建议就医）→ 复盘与复引入（等待期后允许重建任务）；扩展 food_observation 表字段与新增观察日志子表。非目标：不做食谱推荐与营养分析。 | docs/prd/PRD-002.md |
| PRD-003 | 养娃智能体「敏宝助手」 | 目标：把权威知识库与自家宝宝健康数据结合，提供检索增强、带来源引用、带风险分级的 AI 问答、总结分析与每日日记能力。范围：5 阶段旅程（进入对话/知识问答与图片问诊/健康数据查询/记录总结分析与每日日记/多轮会话与安全护栏），12 个用户故事。核心能力：CMPA 知识问答（检索先行+来源标注+未收录引导就医）、图片问诊（拍照/相册上传，AI 看图+知识库分级判断，含视觉模型降级）、自然语言健康数据查询（时间窗解析+数据来源说明）、跨维度总结分析（趋势解读+综合总结卡片+一键周报/月报快捷按钮+生长曲线 P50/P75 解读，可单独回答）、每日日记（手动触发，基于当天记录含图片+对话捕捉的生活事件生成温情日记，可编辑/配图/持久化回看）、语音输入（转文字后发送，回复为文字）、风险分级护栏（症状分级判断，emergency 强制就医引导）、多轮会话与中断恢复、回答反馈闭环。边界：数据私域+健康教育助理，不诊断、不开处方、不替代医生。非目标：AI 写健康记录、诊断用药输出、语音回复（TTS）、非图片类附件、长期个性化记忆、会话历史页、定时生成与主动推送。优先级 P0-P4，预估 22-28 人日，与 TECH-006 执行计划对齐（总结分析/每日日记/图片问诊/语音输入为本 PRD 新增范围，技术方案需扩展）。 | docs/prd/PRD-003.md |
| PRD-004 | 音箱对话渠道「小宝小宝」 | 目标：通过 ESP32 家庭音箱（xiaozhi 固件）为「敏宝助手」提供免掏手机的语音硬件渠道。范围：4 阶段旅程（设备接入与绑定/语音对话/语音录入/会话延续与护栏），9 个 MVP 用户故事 + 2 个二期候选。核心能力：永久有效绑定码绑家庭（不绑人，默认所有家庭用户可用）、唤醒词"小宝小宝"离线唤醒、提问/记录全部走 agent-poc（复用知识库/数据/护栏，音箱只做语音桥，关闭内置闲聊）、语音录入+播报回读确认（敏感记录强制确认）、同唤醒会话多轮追问（8s 静默退出）、跨唤醒会话延续（复用最近 20 条）、风险护栏（emergency 强制就医+免责，播报后不再附加建议）、异常降级（语音反馈优先）。硬件：立创·实战派 ESP32-S3（N16R8+双麦+屏+摄像头），本地模拟（py-xiaozhi）先行。二期：声纹识别区分成员、主动补录提醒。非目标：音箱侧不存业务数据、不建第二套 AI 链路、MVP 不区分说话人。 | docs/prd/PRD-004.md |
| PRD-005 | 医疗健康档案板块重构（按类型定制记录 + 聚合视图） | 目标：把"通用就医表单"重构为按就医类型定制的差异化记录与聚合档案视图，解决疫苗/儿保等类型内容差异大、无法结构化承载的问题。范围：5 阶段 10 个用户故事——类型路由（US-01 独立类型选择页为记录主入口，编辑锁定类型）、疫苗接种（疫苗名+剂次+反应记录；内置免疫程序参考库=一类+常见二类、手动维护；疫苗本按月龄分档展示已完成/待接种/下一针并跟踪至 6 岁、远期剂次折叠；五联等联合疫苗手动标记替代、不自动换算）、儿保检查（体格测量自动同步生长记录、同日冲突默认覆盖；5 维度发育里程碑三态；医生评估+家长问答多条；儿保档案回溯）、就诊记录（主诉/诊断/开药/医嘱，开药可同步药箱、不自动打卡）、其他检查自由兜底、医疗档案聚合页（查看入口，与类型选择页职责分离）、过敏档案（二期）。横切：老数据兼容（类型徽标/编辑分流/疫苗补全引导）、语音录入类型化扩展。优先级：P0 疫苗+儿保+老数据兼容，P1 就诊增强+归口，P2 过敏档案。非目标：疫苗批号追溯/AEFI 上报、AI 医学判断、报告 PDF 导出。 | docs/prd/PRD-005.md |
