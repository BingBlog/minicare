# F07 · 健康记录

> 来源：MVP-PRD.md §2.4.6、§3.2.4  
> 功能 ID：P0-005  
> 优先级：P0  
> 最后同步：2026-03-29

## 功能描述

记录宝宝的过敏表现、用药情况和护理情况。

## 过敏表现记录功能

- 预设常见过敏表现：皮疹、呕吐、腹泻、咳嗽、喘息、湿疹等
- 采用勾选方式选择出现的**表现**
- 记录严重程度（轻度 / 中度 / 重度）
- 支持拍照记录**表现**情况

## 用药记录功能

- 记录用药名称、剂量、频次
- 支持拍照药品标签（仅留档，不做 OCR）

## 保湿护理功能

- 记录保湿护理时间、使用产品

## symptom_types 预设值

`rash`（皮疹）、`vomiting`（呕吐）、`diarrhea`（腹泻）、`cough`（咳嗽）、`wheeze`（喘息）、`eczema`（湿疹）、`other`（其他）

## 数据库表

`symptom_record`、`health_record` 表 — 见 `architecture.md`

## 验收标准（AC）

- [ ] 过敏表现类型可多选勾选
- [ ] 有表现时显示严重程度选择
- [ ] 可拍照记录表现（仅留档）
- [ ] 用药记录可填写名称/剂量/频次
- [ ] 保湿护理可记录时间和产品
- [ ] 保存后归入当日时间线
