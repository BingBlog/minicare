# F05 · 活动记录

> 来源：MVP-PRD.md §2.4.4、§3.2.2

> 优先级：P0  
> 最后同步：2026-03-29

## 功能描述

记录宝宝的运动发育和活动情况。

## 活动类型

- **抬头练习**：记录抬头时长、状态
- **翻身练习**：记录翻身次数、方向
- **爬走练习**：记录爬行/学步时长
- **视力活动**：追视、看卡片等
- **运动活动**：被动操、游泳等
- **户外活动**：晒太阳、散步等

## 输入项

活动类型（抬头/翻身/爬走/视力/运动/户外活动等）、活动时长、活动描述

## 数据库表

`activity_record` 表 — 见 `architecture.md`

## 验收标准（AC）

- [ ] 六大活动类型可勾选
- [ ] 可填写活动时长（分钟）
- [ ] 支持备注描述
- [ ] 保存后归入当日时间线
