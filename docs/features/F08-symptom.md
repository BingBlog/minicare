# F08 · 表现记录

> 来源：MVP-PRD.md §2.4.7、§3.2.5  
> 功能 ID：P0-006  
> 优先级：P0  
> 最后同步：2026-03-29

## 功能描述

记录宝宝的心情和精神状态。

## 心情记录功能

- 采用简单的情绪图标选择：开心 / 一般 / 低落
- 支持自然语言输入

## 精神状态记录功能

- 记录活动量（安静 / 正常 / 活跃）
- 支持简短的状态描述

## 数据库表

`health_record`（情绪字段 `mood`）表 — 见 `architecture.md`

## 验收标准（AC）

- [ ] 心情可通过图标单选（开心/一般/低落）
- [ ] 精神状态可单选（安静/正常/活跃）
- [ ] 支持备注描述
- [ ] 保存后归入当日时间线
