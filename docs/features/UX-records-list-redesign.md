## 一、现状梳理：各记录类型列表条目展示信息汇总

### 1.1 条目整体布局

**现状布局（含 meta 区域）：**
```
[ 类型图标 36px ] [ primary · tags · meta ]  [ summary(右侧数值) ] [ 时间 HH:mm ] [ > ]
                  第二行（有备注时）：note 文字（最多2行，灰色11px）
```

**优化目标布局（meta 合并入 tags）：**
```
[ 类型图标 36px ] [ primary · tags（含原 meta 信息） ]  [ summary(右侧数值) ] [ 时间 HH:mm ] [ > ]
                  第二行（有备注时）：note 文字（最多2行，灰色11px）
```

- **primary**：类型标题（15px 深色加粗）
- **tags**：Pill 胶囊标签（11px 圆角彩色），承载所有分类细节信息，**取代 meta 纯文本区域**
- ~~**meta**：辅助文字（11px 灰色）~~ → **废弃，信息全部迁移到 tags**
- **summary**：右侧核心数值（SummaryMetric chip，14px 加粗带单位）

> **方向决策**：所有原 meta 纯文本信息一律改为对应颜色的 Pill 标签，实现视觉形态统一。
> 各类型 Pill 颜色与该记录类型的主色调保持一致，形成颜色语义体系。

## 二、现状问题分析

### 2.1 信息层级混乱

- **primary 标题语义弱**：「换尿布」「活动」「表现记录」「健康记录」等标题没有区分度，用户扫视时无法快速获取关键信息
- **生长记录数值在 tags 区**：身高体重作为 SummaryMetric 挤在 tags 区，与其他类型的 summary 右侧数值位置不一致，视觉混乱
- **配方奶奶量是最重要信息**，却只出现在 summary（右侧），奶粉类型在 meta 中，重要程度排序颠倒
- **睡眠质量字段已采集但不展示**（`quality` 字段在列表中被丢弃）

### 2.2 信息密度不均衡

- **换尿布**：仅展示类型标签，便便性状是高价值医疗信息，展示不突出
- **健康记录**：体温是最关键数值，展示在 summary 位置合理；但「情绪」字段放在健康记录里容易与「表现记录」重复记录
- **表现记录**：情绪+精神状态，标题「表现记录」对家长不直观（行业通用叫法是「宝宝状态」）

### 2.3 冗余与缺失

- 活动类型标签（洗澡/户外活动等）在 primary 已是「活动」，类型应升格为 primary 核心信息
- 医疗记录中「诊断」字段采集了但未在列表展示（只显示医院）
- 母乳「哺乳侧」在 meta 中展示，信息量太弱，喂养时长更重要

## 三、优化方案（母婴产品视角）

### 3.1 设计原则

母婴记录 App 的核心用户场景是**「1 秒扫读」**：家长手忙脚乱、睡眠剥夺，查看记录时只有 1~2 秒的注意力窗口。

优先级排序：
1. **核心量化数据**（奶量、时长、体温）——家长最关心的数字
2. **状态关键词**（臭臭/嘘嘘、发热、过敏）——需要快速识别的异常
3. **分类细节**（奶粉类型、睡眠时段、活动类型）——次要参考信息
4. **用户备注**——最低优先级，有则展示

## 四、实施优先级建议

### P0（高价值·低成本，立即实施）

1. **活动类型升格为 primary**（当前「活动」无信息量，用户体验差）
2. **睡眠时段升格为 primary**（与活动同样问题）
3. **营养素标签加剂量**（`dose + unit` 字段已有，只是未显示）
4. **生长记录数值移到 summary 右侧区**（布局一致性修复）
5. **meta → tags 统一改造**（方向已确认，所有 meta 文本改为对应 Pill，视觉形态统一）：
   - 配方奶：每个奶粉类型生成带颜色 Pill（含勺数），替换 meta 文本
   - 母乳：哺乳侧改为粉色 Pill（左乳/右乳/双侧）
   - 辅食：食物名称改为暖黄 Pill
   - 睡眠：时段并入 primary 后，新增睡眠质量 Pill
   - 医疗：医院名称改为淡蓝 Pill，新增诊断 Pill

### P1（中等成本，体验提升明显）

6. **活动强度 Pill**（字段已有，类型升格 primary 后 tags 位补充强度，不额外占用空间）
7. **表现记录标题改为「宝宝状态」**（用户语言优化）
8. **健康记录移除情绪展示**（减少与「宝宝状态」的信息重复）

### P2（需评估）

9. **发热/过敏图标恢复**（刚去掉图标，需要确认产品取向：纯文本更简洁 vs 图标加速识别）
10. **情绪标签恢复图标**（同上，需产品决策）
11. **血便红色警告强化**（特殊场景处理）
12. **母乳无时长时显示「—」**（细节优化）
