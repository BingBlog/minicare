# F01 · 用户登录与注册

> 优先级：P0  
> 最后同步：2026-03-29

## 功能描述

MVP 阶段仅支持**手机号**方式注册与登录，不支持微信/Apple 等第三方登录。

## 登录方式

- **验证码登录**（默认）：输入手机号 → 获取短信验证码（60 秒倒计时）→ 填入验证码 → 登录；首次使用（未注册）时，登录即注册。
- **密码登录**（可选）：输入手机号 + 密码 → 登录；密码由首次注册后在「我的」中设置。

## 业务规则

- 手机号格式校验：大陆 11 位手机号，不合法时禁用「获取验证码」按钮并给出红色提示。
- 登录成功后，若检测到**无宝宝档案** → 跳转引导页（→ 见模块 02-onboarding）；若有档案 → 直接进入首页。

## 交互流程

```mermaid
flowchart TD
    A([App 启动]) --> B{已登录?}
    B -- 是 --> C{有宝宝档案?}
    B -- 否 --> D[显示登录页]
    D --> E{选择登录方式}
    E -- 验证码 --> F[输入手机号]
    E -- 密码 --> G[输入手机号+密码]
    F --> H[获取短信验证码\n60秒倒计时]
    H --> I[填入验证码]
    I --> J[登录/自动注册]
    G --> J
    J --> K{登录成功?}
    K -- 失败 --> L[提示错误信息\n可重试]
    L --> E
    K -- 成功 --> C
    C -- 否 --> M[显示引导页\n创建宝宝档案]
    C -- 是 --> N[进入首页]
```

## 验收标准（AC）

- [ ] 大陆 11 位手机号格式校验生效，不合法时按钮置灰
- [ ] 获取验证码按钮 60 秒倒计时，期间不可重复点击
- [ ] 未注册手机号登录即注册，自动生成账号
- [ ] 密码登录与验证码登录可自由切换
- [ ] 登录成功后：有档案 → 首页；无档案 → 引导页
- [ ] 登录失败展示友好错误提示，支持重试
