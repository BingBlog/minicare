# F06 · 尿布记录

> 来源：MVP-PRD.md §2.4.5、§3.2.3  
> 功能 ID：P0-004  
> 优先级：P0  
> 最后同步：2026-03-29

## 功能描述

记录宝宝的大便、小便情况。

## 大便记录功能

- 采用选项式勾选设计，避免打字输入
- 记录排便次数、性状（稀便 / 软便 / 便秘 / 血便等）
- 支持拍照记录（上传便便图片，**仅做留档，不做 OCR 识别**）
- 提供 Bristol 大便分级对照图作为参考

## 小便记录功能

- 记录换尿布次数和尿湿程度
- **MVP 不实现预警推送**（预警功能留到后续迭代）

## stool_types 预设值

`loose`（稀便）、`soft`（软便）、`hard`（便秘）、`blood`（血便）、`mucus`（黏液便）、`normal`（正常）

## 数据库表

`diaper_record` 表 — 见 `architecture.md`

## 验收标准（AC）

- [ ] 排便次数可通过步进器调整
- [ ] 大便性状可多选勾选
- [ ] 可拍照附件（仅留档）
- [ ] Bristol 对照图可在页面内查看
- [ ] 换尿布次数可通过步进器调整
- [ ] 尿湿程度可单选（少/中/多）
- [ ] 保存后归入当日时间线
