## 三、评测结论

### 3.1 Recall@10 达标（97.8%）

45 题中 44 题 gold 条目对应知识块在 top10 被命中。唯一未命中 **A-04**（"牛奶过敏会发展成哮喘吗"，gold=KB-A3 过敏进程）：
- 根因：**知识覆盖缺口**——"过敏进程"主题在库中仅 2025共识-35（过敏性疾病早期识别）一个弱相关块，向量未排进 top20
- 结论：非检索问题，是源材料中过敏进程内容薄弱；后续补录相关指南（如过敏进程综述）可解

### 3.2 有害召回 16 条为"伪有害"（映射口径失真）

根因：**KB 映射表按"每条目 top3 全取"生成，条目间块重叠严重**：
- `严重过敏共识-31`（诊断标准总章）同时被 KB-C1/C2/C5/C6 等 5+ 条目映射 → 一进 top5 全算有害
- `2025共识-16/17`（部分/深度水解配方）同时被 KB-B7 与 KB-E4 映射 → 配方类题目命中不算错

→ 不是检索召回了无关内容，而是映射表粒度太粗（一个块被多个条目引用）。修正方向：映射表改为"条目 → 唯一主块"（人工精修 47 条），或有害判定改为"命中的块与题目主题语义无关"（人工标注）。

### 3.3 检索链路有效性（混合检索验证）

| 问题 | 混合检索 top1 | 判定 |
|---|---|---|
| A-01 鸡蛋红疹是过敏还是不耐受 | 2025共识"引入熟鸡蛋防过敏" | ✅ 语义相关 |
| D-03 深度水解还是氨基酸 | 广东共识"牛奶蛋白过敏的婴儿" | ✅ |
| F-01 花生后嘴唇肿喘不上气 | DRACMA "Oral Allergy Syndrome" | ✅ 急救相关 |

FULLTEXT 与向量双路在 RRF 融合下均贡献召回；向量路对口语化问法（"拉血便"→"血便"）有补充价值。

## 四、遗留与建议

1. **映射表精修**（P1）：47 个 KB 条目 → 唯一主块，人工复核后有害召回口径才能真实评估
2. **过敏进程知识补录**（P2）：A-04 暴露的覆盖缺口，补 1-2 份过敏进程/自然病程材料
3. **上线闸门**：Recall@10 ≥90% 已过；待映射精修 + 有害召回口径修正后，可正式启用 M02 §7 上线门
4. 检索延迟/吞吐（P99 ≤500ms）未测，属于 minicare-server 侧联调项
