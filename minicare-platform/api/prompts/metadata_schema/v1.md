# 元信息 Schema 归纳 v1

你是医学知识库的**元数据架构师**。下面给你若干份文档的「标题树 + 开头正文」样本，
请归纳出一套**全库通用**的元信息字段（schema）。

## 归纳要求

1. 字段数控制在 **28–36 个**。太少不足以做检索筛选与加权，太多会让抽取信噪比下降。
2. 这套字段要**服务于三件事**：
   - **检索过滤/排序**：能拿来精确筛的**枚举或数值**字段（地区、证据级别、月龄区间、推荐强度…）；
   - **检索加权**：能提升相关度的**语义标签**（主题、症状、过敏原、配方类型、目标人群…）；
   - **合规与溯源**：来源、机构、年份、许可、利益冲突。
3. 字段名用 `snake_case` 英文；`label` 用中文；`desc` 一句话说清语义。
4. `type` 只能是：`string` / `number` / `array` / `enum`。用 `enum` 时必须给出 `values`。
   **凡是"能被精确筛"的维度，优先做成 `enum` 或 `number`，不要用自由文本**（自由文本没法过滤）。
5. `hint` 写给抽取器看：什么算命中、怎么写、什么时候留空。
6. **必须包含这 7 个基础字段**（键名一字不差）：
   `source_name` `publisher` `year` `region` `evidence_level` `applicable_age` `license`
   其中 `region` 的 values 必须是 `["cn","intl"]`；
   `evidence_level` 的 values 必须是 `["guideline","consensus","RCT","policy","edu"]`。
7. **必须包含下面这 12 个字段**（键名一字不差；它们经人工评审确认对检索/权重/合规/医疗安全必要，
   请为它们写好 `desc` 与 `hint`，也可以在此基础上再补充你自己的字段）：

   | key | 为什么必要 |
   |---|---|
   | `symptoms` | 家长最可能用**症状**提问（便血、湿疹、呕吐），只抽疾病名会漏检索 |
   | `age_min_months` / `age_max_months` | 原先只有自由文本的"适用年龄"，**无法做区间过滤**；这两个是数值型 |
   | `recommendation_strength` | 推荐强度（强/弱/条件）是检索加权的核心信号。**values 必须是** `["强推荐","弱推荐","条件性推荐","未分级"]` |
   | `evidence_quality` | 证据**质量**分级 —— 与 `evidence_level`（**文献类型**）是两个维度，原先混为一谈。**values 必须是** `["高","中","低","极低","未分级"]` |
   | `contraindicated_populations` | 禁忌**人群**（与"禁忌做法"不同），医疗安全必需 |
   | `diagnostic_criteria` | 诊断标准/要点，临床场景的高频查询 |
   | `conflict_of_interest` | 合规必备的利益冲突声明 |
   | `version_or_update` | 版本/更新说明，时效性加权要用 |
   | `emergency_management` | **急救处置步骤** —— 危急场景下容错为零，必须能被直接检索到 |
   | `referral_criteria` | **转诊/就医指征** —— 家长最需要的判断依据（"什么时候必须去医院"） |
   | `weaning_protocol` | **转奶 / 配方转换方案** —— 本知识库的核心服务场景 |

   ⚠️ 注意：像 `emergency_management`、`weaning_protocol` 这类字段，**多数文档本来就该是空的**
   （只有相关主题的文档才有）。这不是字段设计得不好，**不要因为样本里普遍为空就把它删掉或替换**。

8. 领域是**婴幼儿牛奶蛋白过敏（CMPA）与过敏预防**，其余字段请据此设计有区分度的
   （如涉及的过敏原、配方类型、核心建议、风险禁忌、剂量信息）。

## 输出格式

只输出 JSON，不要任何解释文字：

```json
{
  "fields": [
    {
      "key": "topics",
      "label": "主题标签",
      "type": "array",
      "desc": "文档覆盖的核心主题",
      "required": false,
      "values": [],
      "hint": "3-8 个名词短语，如「牛奶蛋白过敏」「辅食添加」"
    }
  ],
  "reasoning": "一句话说明为什么是这几个字段"
}
```

## 边界

- 样本里没有体现、但你判断对检索有价值的字段，也可以提出来（这正是让你归纳的意义）。
- 不要发明需要外部数据才能填的字段（如影响因子、被引次数）。
- 已有字段若在样本里普遍缺失，说明它抽不出来，应当删掉而不是硬留。
