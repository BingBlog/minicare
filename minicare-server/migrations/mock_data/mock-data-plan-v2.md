### 1.2 宝宝健康背景

- **牛奶蛋白过敏（CMPA）**：出生后不久确诊，0–45天使用普通配方奶（初期不知情），第46天起换用**深度水解奶粉（不含乳糖）**，第70天起逐步加入**深度水解奶粉（含乳糖）**，测试乳糖耐受
- **就诊与换奶间隔**：Day 39（2026-02-02）就诊已建议换深度水解（无乳糖），实际 **Day 46（2026-02-09）** 才完成换奶，叙事上解释为：备货与到货、家长观察与过渡、避免与急性感染期用药/喂养混在同一段调整窗。
- **数据记录角色**：`recorded_by` 字段使用两个 userId（爸爸/妈妈轮流记录）
  - 主记录者：`fbcccfbd-a450-45d8-be43-e5770de80359`（妈妈，记录占 65%）
  - 副记录者：`b42b4c6f-5a57-413d-815a-af16e790f4a1`（爸爸，记录占 35%）

- **Day 46（2026-02-09）**：首次换用**深度水解奶粉（不含乳糖）**（`note` 标注"换深度水解奶粉（无乳糖）"）

### 3.2 尿布记录规则（diaper_record）

> 字段映射：`diaper_type`: 1=wet（小便）, 2=dirty（大便）, 3=mixed（混合）, 4=dry（干净）  
> `poop_type`：**库内与前端一致，存英文 key**（见 `POOP_TYPE_LABELS`）：`normal_soft` / `loose` / `watery` / `hard` / `bloody` / `normal_form`。展示文案由前端映射，**不要**把中文长句写入 `poop_type`。  
> `diaper_count`: 一次记录涵盖的尿布数（通常1）

胎便、过渡便等当前枚举未覆盖的性状：**写入 `note`**（可含「胎便」「过渡便」描述），`poop_type` 可用 `loose` 或留空以兼容旧数据。
