> 给谁看：**敏宝家长**（主线，占 ~70%）+ **从 GitHub 来的工程师**（背书区，页尾 ~30%）
> 核心原则：**主线全说人话；技术内容降级不删除**——只换位置、换说法。
> 保留术语白名单（家长圈日常词，**不翻译**）：排敏 / 转奶 / 深度水解 / 适度水解 / 氨基酸配方 / 便血 / 皮疹 / 便便 / 复诊。

- **三个瞬间**（各配一张对话/界面示意，用现有绿底卡片式）：
  1. **凌晨，便便里有一丝血**：你心里咯噔一下，拍照记录。它给出一条清晰的判断线——什么情况连夜就医、什么情况先观察并记录，第二天联系医生。「要不要去医院」不再靠猜。
  2. **排敏第 2 天，想加第二种辅食**：它知道第一种还在观察期、距上次皮疹才 3 天，会劝你「再等一天」——而不是等你加完才马后炮。
  3. **看完医生，医嘱怕忘**：一句「帮我记下医嘱」，它整理成任务卡，到点提醒；下次复诊自动带上这段时间的记录。
- **「记了就有用」说明段**（把 03 原理翻译成人话）：
  「你记的每一笔，都会汇成它脑子里的『宝宝现状小结』——转奶还差几天、哪些食物已确认过敏、症状多久没记。有了这份心里有数，它的回答才有前提：不会车轱辘话，更不会瞎下结论（没记的，它不装懂）。」

## 三、执行要点（改的时候对照）

1. 先落**翻译表**替换全站文案，再动**结构重排**（两步分开改，方便回退）
2. 所有标题自检一句：**这句话是「我们做了 X」还是「你得到 Y」？** 前者改后者
3. 数字出现的地方：正文给人话 + 括号留精确值；纯技术数字只进背书区
4. 配图 caption 全部重写一遍（人话 > 术语）
5. 改完自查清单：全文搜「信号 / 注入 / 闭环 / 闸门 / 平台化 / 智能体 / 管线 / 召回率」，确保只剩白名单内或背书区
